# DSH Workbase · 工作台 PRD

整理日期：2026-11-12。本文是功能需求的唯一入口，归并项目、会话、待办、插件更新、备份恢复及技能／MCP／RSS扩展的已确认需求。实现与验收状态见 [开发日志](../.agents/notes/dev-log.md)，共用视觉规则见 [UI 设计](UI-DESIGN.md)，全部交互演示集中在 [设计原型](ui/ui-directions.html)。演示不表示正式能力已实现。

原型优先将可复用功能融入原始工作台UI：待办详情及统计跳转共用项目数据和编辑器，技能／MCP／RSS使用工作台概览内的管理面板；顶部功能预览仅提供直达入口。插件更新及备选布局／配色保留为隔离页面演示，不以独立模拟页面替代已有工作台功能。

## 1. 定位与范围

为 DeepSeek Harness 提供以项目为中心的个人工作台，集中查看项目、会话与下一步行动。产品名为 DSH Workbase，npm 包及插件加载名为 `dsh-workbase`，中文界面名称为「工作台」。

基础范围包含项目与会话管理、用户手动待办、Agent 工具待办、全局搜索、首页配置及主题，后续扩展包括插件更新、备份恢复和技能／MCP／RSS管理。会话自动提取、候选确认、待办后台执行、多人协作、云端同步、复杂排期、多级子任务和看板不属于当前范围。

设计原型已经确认为开发基线；当前插件适配 Harness `0.2.2-rc.1`，Web 已有验收记录，真实桌面 profile 尚待验收。

所有弹窗的底部文字操作采用统一尺寸与圆角，宽度随文案，主次和危险操作保持颜色区分；待办会话模式与发起按钮保持组合样式，具体规格见 UI 设计。

## 2. 对象与数据归属

### 项目

每个项目绑定一个 Harness 已注册工作区和一个本地目录；自动汇总已注册工作区，不扫描磁盘。空项目允许没有会话，必须有目录。

名称以 Harness 工作区为权威。重命名只更新显示名称，不更改文件夹名、路径或身份。目录默认显示 2×2 实心四圆点与文件夹名称，不增加 `/` 前缀，悬停提供完整路径；首页点击目录复制原始完整路径，详情点击目录切换项目，弹窗上方显示项目名、下方显示完整路径，两行各自保持单行并在超长时省略；详情更多菜单提供复制路径。

插件生成稳定 `projectId`，以 `workspaceId` 记录宿主绑定，目录用于规范化和重复检测。同名不同目录的项目保持独立。移除保留身份、待办、设置和个人标记，再次添加原工作区或原目录时恢复；外部删除后出现新 workspaceId 时要求明确选择恢复原项目或作为新项目，不按路径静默合并。

### 会话

沿用 Harness 原会话及更新时间，以用户主会话为列表单位，子代理留在原会话上下文中。打开会话直接进入宿主原会话，不创建副本。

会话预览与待办详情共用居中弹窗尺寸：面板宽度90%、最大1120px，高度为可用区域减50px，650px及以下全宽。直接以会话名称作为固定 header 的标题，不显示「会话预览」标签；标题保持单行，超长省略，悬停可查看完整名称。状态、所属项目及更新时间合并展示，正文独立滚动，标题与底部操作保持可见。加载、空内容与失败均提供明确反馈，失败可重新读取；底部可关闭预览或打开原会话。菜单、字段开关、项目切换及预览颜色适配全部主题的明暗外观。

会话归档读取宿主状态。待办不依赖会话生命周期，删除会话不会连带删除项目待办。永久删除需确认，由工作台独立删除目标和 SUBAGENT 子会话的日志、缓存与列表关联，保留独立 fork 和工作树代码；运行中会话及归档项目禁止删除。当前只清理归属可验证的官方 JSONL 专属目录，未知后端或底层能力缺失时拒绝。

### 待办

每条待办属于一个 projectId，使用全局唯一 ID，记录标题、备注、可选优先级、附件引用、创建者、创建与更新时间、完成时间及并发版本。标题必填，上限 500 字符；备注上限 10,000 字符。优先级为高／中／低或未设置，可清空；旧待办自动补齐未设置及空附件列表，保留旧图片引用。附件不限格式，旧图片与新文件合计最多 10 个，单个不超过 10MiB，只保存宿主不可变附件引用，不在工作台 JSON 保存文件正文。不加入评论、变更记录和截止日期。

选择、拖入或粘贴附件后直接上传，不要求再点保存确认。已有待办上传附件不提前保存标题、备注和优先级草稿；新建待办先建立身份，若标题为空则保留文件，标题编辑结束后自动继续。多文件串行上传，失败只保留未成功的文件供重试，成功文件不重复上传；上传中禁止关闭、重复操作和发起会话，失败文件未移除或重试成功前禁止发起会话。

发起会话使用 Harness 官方会话控制器在所属项目创建所选模式的会话，草稿按「待办任务：标题」「待办 ID：ID」「任务描述：」三项依次排布；描述内容另起行并保留原始Markdown，空一行后追加「请按上述要求处理此待办，并在验证完成后更新待办状态。」。不另加优先级行，全部附件交接完成后打开会话，由用户发送。详情页将`note`字段显示为「描述」，空内容提示「暂无描述」，底层存储与工具参数不变。附件读取失败不创建会话，交接失败不导航；图片继续遵守宿主消息限制。该操作不保证 Agent 自动执行或自动完成待办，状态更新依赖 Agent 的工具调用及权限。

状态只有「待处理」「已完成」。完成时记录完成时间，重新打开时清除，不从日志推测历史完成时间。旧进行中数据按待处理兼容，已有已完成身份保留。

用户与 Agent 创建的待办共用列表，来源显示为用户或 Agent；首版不保存来源会话和原文摘录。待办由宿主持久化存储域保存，目录失效时仍可读取与编辑。

## 3. 页面与状态恢复

宿主侧栏承担全局导航，工作台内部不增加侧栏或固定项目导航列。工作台使用全宽首页与项目详情两个视图。

- 共享 Header：全局搜索、同步状态与最近活动、添加项目、工作台设置。
- 首页：居中快捷输入、最近会话、可选统计卡、全宽项目总览。
- 详情：两行项目头部、会话与待办两栏；窄屏为互斥页签。

点击宿主工作台入口恢复最近项目与位置，无有效历史时进入首页，项目已不可用时回首页并提示。首页和各项目分别记忆位置；全局搜索词与类型、待办和快捷输入草稿、窄屏页签及滚动位置保留。未提交草稿和滚动由浏览器保存，业务数据、设置与布局偏好由宿主持久化。

## 4. 项目管理与个人整理

- 添加支持「打开已有项目」，输入或粘贴绝对路径，也可通过右侧文件夹按钮选择目录；点击输入框仅编辑路径，Alt + ↓ 打开目录选择器。或在已配置根目录下创建同名文件夹。根目录无效、名称非法、目录不可用或同名文件夹存在时保留输入，不覆盖文件。
- 重复添加仅提示，不新建身份、不自动进入项目；可从提示进入已有项目。
- 默认宫格，可切换列表；视图和显隐分别保存，切换保留全局搜索词、筛选及排序。
- 两种视图共用七项字段：目录、最近活动、状态、近期活跃、待办、归档、最近会话。名称与主要操作始终保留；隐藏字段移除对应列或区域。
- 近期活跃为最近 7 天更新的未归档会话；待办为未完成数；归档为归档会话数；最近会话取更新时间最新的会话，包含归档。项目最近活动取会话更新时间与待办变更时间的较大值。
- 宫格默认显示目录、最近活动、近期活跃、待办、归档、最近会话；列表默认显示目录、最近活动、状态、近期活跃、待办、归档。已有偏好保留。
- 项目与会话均提供互斥「活跃／归档／收藏」标签。收藏范围包含全部收藏的活跃和归档内容，归档限制仍有效；重复点击当前标签保持选择。项目标签全局保存，会话标签按项目保存，旧组合收藏筛选兼容为单一标签。
- 置顶优先，组内按最近活动或会话更新时间倒序。取消置顶不修改业务更新时间；置顶与收藏彼此独立，不改变首页最近会话、搜索和统计口径。
- 置顶仅在项目卡片、列表和会话条目悬停或键盘聚焦时显示，详情项目标题不显示置顶；收藏只在更多菜单，条目不显示星标。菜单不重复提供置顶。触控入口保持可达。
- 项目更多菜单中收藏紧跟重命名，详情随后提供复制路径及其他操作。归档内容允许个人整理，但不解除只读限制。
- 重命名预填宿主名称，Enter 保存、Esc 取消；失败保留旧名与输入。
- 移除需二次确认，运行中会话先停止。移除保留数据，重新添加恢复身份；失败回滚，不显示假成功。
- 目录异常持续提示原因及重新检查入口，历史会话和待办仍可访问。修改绑定目录按第 8 节处理。
- 项目规则与全局规则：工作台提供一份全局规则与每个项目一份规则的编辑入口，保存前预览最终生效内容；规则必须被 Agent 实际读到，宿主缺少稳定的规则加载约定时明确拒绝，不模拟已生效。项目规则是替换还是追加全局规则、编辑形态与写入位置待定。
- 创建项目时初始化目录：在已配置根目录下新建项目目录时可选初始化模板（只建结构、生成模板文件或执行初始化命令），默认不初始化；初始化只作用于刚创建的空目录，目标非空或写入失败时回滚，不显示假成功。

## 5. 会话、待办与 Agent

### 会话

详情展示单行标题、时间及运行／归档状态，长标题可查看全文，不展示重复摘要。检索统一用 Header，不设置局部会话搜索框。

会话工具行提供筛选与新建，Header 不重复放新建。不可执行项目、失效目录或加载状态禁用新建并说明原因。模式与模型从宿主目录读取，使用真实名称和标识，不将原型示例作为接口参数。

支持重命名、归档及恢复，失败保留原状态。运行中会话不得被静默终止，要求先停止再操作；首版按单条操作设计。

### 手动待办

- 输入标题按 Enter 快速创建，成功后清空并保留焦点，失败保留草稿；「完整新建」位于快捷输入右侧，提供标题、Markdown 备注、可选优先级及通用附件。点击标题打开唯一详情弹窗，状态只读；状态、项目及创建信息固定在header下方，与会话预览摘要共用位置和边距，标题与优先级在下方内容区紧凑排列，备注与附件继续单列展示。归档项目只读。附件不限制扩展名或格式，最多10个（与旧图片合计）、单个10MiB，支持空文件、选择、拖入、粘贴、下载、移除和失败后继续上传；图片显示缩略图，解码失败回退文件图标。首次保存后上传失败保留同一卡片身份、已成功引用和剩余文件，不重复创建。保存及交接中禁止重复操作，存在未上传附件时禁止发起会话。并发变更保留草稿，显式接受最新版本后可继续保存。
- 待办详情底部集中会话模式、发起会话和保存，关闭仅位于右上角。发起会话先保存文本改动，读取全部附件后才按所选模式创建空会话，依第3节格式填入任务标题、待办 ID、描述和处理要求，并交接附件文件名和原始字节。只准备草稿，由用户发送；附件读取或交接失败不导航、不清空待办。工作台持有会话引用，真实界面接管后才释放，避免输入壳及附件在导航前销毁。宿主图片准入限制仍生效，其他图片格式以通用文件交接。
- 点击行首完成或重新打开，点击标题查看详情；标题单行省略，完整内容在详情查看。行尾删除按钮仅当前行悬停或键盘聚焦时显示，触屏常显；点击直接删除，顶部提示提供 5 秒撤销，恢复原 ID、图片引用、来源及完成时间。只保留最近一次删除撤销，宿主重启后撤销失效。
- 待办列表和卡片不展示备注正文，避免长文本改变行高；备注在详情中查看和编辑，仍参与列表筛选及全局搜索。
- 默认展开待处理，已完成入口固定在下方。两个分组始终可见且只展开一个，包括空组；点击展开中的组会切换到另一组。
- 两组独立滚动并记忆位置，切换使用约 200ms 动画，减少动态效果时立即完成。
- 完成或重新打开只迁移条目和更新计数，不切组；保持焦点在下一条、上一条或输入框。搜索和统计定位才展开目标组、滚动并高亮。
- 状态变更提供 5 秒撤销提示和「撤销最近一次状态变更」入口；撤销检查当前版本及可写权限，再次变化后不覆盖新修改。普通提示不夺走撤销能力。
- 已完成按完成时间倒序；待处理先按高／中／低／未设置排序，同优先级按最近更新倒序。支持标题／备注搜索和优先级筛选，列表显示优先级与附件总数。
- 待办工具区只占一行：点击固定搜索图标，将添加框原位切换为搜索框，完整新建的位置切换为优先级筛选。两种模式输入框和按钮尺寸一致，搜索图标不变；切换采用300ms上下翻转，返回时反向翻转，减少动态效果偏好下直接切换。搜索即时生效，Enter不创建待办，输入法确认不触发快速添加；再次点击搜索或按Esc返回添加、清除筛选并恢复原草稿。写入及翻转期间阻止重复提交和切换，创建失败保留草稿；归档项目仍可搜索，禁止新增。
- 「完整新建」沿用同排40px次要按钮规格；优先级筛选显示「全部／未设置／高／中／低」，详情显示「未设置／高／中／低」，避免重复后缀挤压。列表与卡片的辅助信息依次为优先级、来源时间、附件数量。

### Agent 工具

| 工具 | 能力 |
| --- | --- |
| `workbase_list_todos` | 查询当前项目；可选 summary、status、query、priority，摘要不含备注和附件引用，保留附件数量；无参数沿用完整返回 |
| `workbase_get_todo` | 单项完整详情、图片与通用文件引用和最新版本 |
| `workbase_create_todo` | 创建标题、备注、可选优先级，来源记为 Agent |
| `workbase_update_todo` | 修改标题、备注、优先级或完成状态 |
| `workbase_delete_todo` | 删除当前项目待办，要求读取到的版本号 |
| `workbase_attach_todo_image` | 将当前会话消息中已有图片附到待办，要求最新版本，不接受跨会话标识、路径或 URL |
| `workbase_remove_todo_image` | 按版本移除卡片引用，不删除共享图片对象 |
| `workbase_read_todo_image` | 查看已附到当前项目待办的图片，返回模型可查看的图片内容 |
| `workbase_attach_todo_attachment` | 附加当前会话真实 file 消息块中的引用，核验宿主文件字节及归属，要求最新版本 |
| `workbase_remove_todo_attachment` | 按版本移除通用文件或旧图片引用，不删除共享对象 |
| `workbase_read_todo_attachment` | 返回已附到待办的通用文件或旧图片，文件通过宿主只读引用提供 |

执行身份限定所属会话的当前项目，不允许跨项目读写。「项目配置 → 全局配置 → 允许 Agent 管理待办」默认开启；开启后允许创建、查询、编辑、删除及修改完成状态，关闭后仅允许查询，用户操作不受影响。全局开关作用于已有及新增项目，归档项目仍禁止写入。删除要求版本匹配，不覆盖用户的最近一次删除撤销记录；Agent 不能调用用户撤销接口。旧逐项目状态限制在首次保存全局配置前保留，保存后统一使用全局选择。

同项目写入串行，编辑按版本检查，失败不产生半条数据；不按标题自动去重。用户与 Agent 并发写入不得覆盖已有内容。

图片使用所有者专用二进制 HTTP 路由，单独限制正文大小，JSON RPC 仍保持 32KiB 上限。读取必须匹配项目与卡片上的图片引用；写入校验归档、全局 Agent 权限及版本。Agent 附图先核验当前会话消息中的真实 image 内容块，再交给宿主验证存储数据；单凭 SDK attachment 接口不构成会话归属校验。保存失败不发布图片引用，未关联对象由宿主生命周期管理。

## 6. 首页、搜索与设置

### 首页

四个模块可分别显示：快捷会话、数据统计、最近会话、项目总览。快捷会话、数据统计和项目总览默认开启，最近会话默认关闭。隐藏不删除数据或草稿；全关时提供从 Header 设置恢复的提示。

快捷输入保留现有圆角输入卡、文本区、左侧添加／项目／模式、右侧模型／发送和下方分支条布局。添加弹窗复用 Harness 官方命令菜单，支持宿主提供的附件、引用和命令；项目弹窗使用官方菜单与文件夹图标，仅显示项目名，不显示路径，归档或目录不可用的项目不可选择。模式弹窗按官方预设名、说明和可用状态展示，控件位置不变。模型弹窗复用同一待发送会话的官方模型控件，支持提供商、模型及模型支持的推理强度选择；选择未完成或模型不可用时禁用发送，提交保留官方选中的推理强度。Enter 换行，⌘／Ctrl + Enter 发送，输入法组合期间不发送。未发送会话按项目与模式复用，结构化草稿保留引用身份并由浏览器保存；附件上传和命令提交交给官方输入服务，宿主接受首消息后打开会话。

快捷输入项目与模型菜单向下展开，与按钮间隔8px；高度不超过360px和工作台／可见视口下方剩余空间，底部保留8px。超出时菜单内部滚动，模型列表保留搜索框，不因选项增多向上覆盖输入区。

快捷输入复用 Harness 官方语音输入实验套件：套件挂载麦克风组件后，在模型与发送之间显示入口，未挂载时隐藏，不自动启用或安装。录音、波形、停止、取消、重试、模型准备及麦克风权限交给官方组件；停止后整段转写并插入草稿，不自动发送。插入使用录音开始时的textarea选区及宿主草稿版本，转换引用、引用块与命令的原子节点坐标，保留未替换引用及附件。转写期间编辑导致版本冲突、发送锁定或超过20000字符时保留结果并沿用官方手动插入入口，不覆盖新草稿。活动展开期间隐藏辅助控件，保留正文编辑、暂时禁止发送；切换项目／模式、离开输入卡或停用套件时取消旧活动，旧结果不回填到新会话。官方只提供活动展开布尔通知，具体录音与识别阶段由组件自身展示。

语音入口显隐动态跟随套件启用状态：已安装但停用时隐藏，启用且官方组件挂载时显示，停用后撤下组件、取消活动并恢复普通工具栏，重新启用后恢复入口。订阅官方插槽注册变化，不缓存首次启用结果；已启用但模型未准备时保留官方准备提示入口。

快捷输入支持拖入文件／目录、粘贴剪贴板图片与添加菜单选择文件，三者委托 Harness 同一文件导入入口。桌面端有真实路径的普通文件和目录作为 `@路径` 引用，图片作为附件上传；网页端目录不受支持时显示宿主拒绝原因。普通文字粘贴保留原生行为，文字与图片同时粘贴时保留文字。拖入卡片时高亮，离开或放下后恢复；阻止文件在当前页面打开。按当前会话权限与图片数量、单张和总大小限制校验，拒绝保留已有草稿。附件显示上传中／失败，失败可重试或移除，上传未完成或失败时不发送。

切换项目或模式时，先保留原输入会话，待目标会话接收附件并通过官方服务重新绑定上传后，再交接结构化正文与引用、移除原附件并释放旧引用。空正文不覆盖目标已有草稿；目标拒绝或加载失败时保留原草稿及附件，可重试或继续选择项目。连续切换取消过期目标，只有最后目标接续附件。输入服务加载或交接失败期间禁用正文编辑与发送，项目选择仍可用；附件对象仅在当前页面生命周期内保留，不承诺跨重启恢复。

首消息必须保持原文。创建失败保留输入；已创建会话但首消息或跳转失败时保留原会话 ID，并允许打开或重试，不重复创建；确认首消息成功后清空草稿。

分支与工作树恢复自实现前的 Forge 方案：宿主官方 `dsh-experimental-forge-bundle` 启用并挂载 forgePanel 时显示整个分支条，禁用或卸载时隐藏；异步挂载及运行中启停持续重新探测。Git 项目可选择本地基准分支，非 Git 项目保留提示、不提供工作树开关。项目分支仍沿用原项目目录 Git 只读查询。工作树通过官方 `forgePanel.requestWorktree` 登记，首消息入队后由 Forge 在回合开始前创建并切换目录；工作台不自行执行工作树创建，不调用 `worktrees.create` 绕过面板，也不提供自建降级。请求未接受则保留草稿和原会话，允许重试。历史自建工作树及代码不作物理删除或自动迁移；工作台删除会话不移除工作树，官方归档清理由宿主设置决定。

宿主更新后的维护入口为 `npm run host:check` 与 `docs/HOST-COMPATIBILITY.md`：生成只读报告并对照显式接受的基线。新增官方等价能力先确认公开契约与安全边界，再优先使用宿主、自实现兜底，不根据同名方法自动调用。

最近会话按跨项目会话更新时间取卡片最多 5 条；按钮数量按面板可用宽度和实际标题宽度动态计算，展示能完整容纳的最新连续会话。按钮区域相对输入框左右各留空白，宽屏允许超过 3 条。排除归档和不可访问会话；目录异常但仍可读的历史会话允许查看。卡片窄屏折行，按钮固定一行并省略标题；不增加区域标题、查看全部或展开入口。

统计卡包括运行中、最近 7 天会话、未完成待办及项目诊断。可见卡片按实际数量均分行宽，隐藏项不留空位；四卡在统计区域宽度720px及以上保持四列，420–719px采用两列，419px及以下单列。运行与近期会话有明确交集，待办区分用户／Agent数量，不推测今日新增。诊断主值汇总目录不可用、列表缓存异常、孤儿子代理残留与空会话的记录数，与其他统计卡使用同一数字样式；下方摘要只显示数量大于零的异常类型，不显示零值项，例如仅有6个空会话时显示「空会话 6」。四项检查均完成且无异常时才显示「检查正常」，能力缺失或读取失败显示「检查未完成」。状态图标使用成功／危险／中性色，不伪造全部正常。

项目诊断保留 Harness 目录可用性检查，增加两类会话检查：普通冷会话的官方缓存缺失、不兼容或缺少标题投影，以及母会话已从内存和磁盘消失的孤儿子代理。缓存检查覆盖登记项目、未分组和归档普通会话，跳过 IM、子代理、已加载及活动会话；标题投影允许空值，不能把合法未命名会话当异常。孤儿检查包括普通和播种型子代理，排除用户 fork、已加载子代理和母会话尚存的记录；日志存在但头部损坏、目录枚举失败或物理探测失败均不能判为已删除。检测仅读头部和官方缓存，不读取完整正文；每个检查独立显示完成、能力缺失或失败。普通快照同步与手动「重新检查」更新结果。按钮位于「项目诊断」标题同一行右侧，执行检查时显示「检查中…」，修复期间禁用并显示「处理中…」；说明和最近检查时间位于标题行下方。

空会话检查使用官方 `sessionListMetadata.blank === true` 且 `lastPromptAt === null` 的普通冷会话，排除 IM、子代理、播种／分支、有后代及已加载／活动会话；不按标题、文件大小或正文预览为空判定。缺少或损坏的官方投影标为检查未完成，可先重建列表缓存再复查。新增「空会话」分类、单条删除及「一键删除全部空会话（数量）」；仅清理可写项目及未分组候选，归档项目保持只读。确认后按最多20条且受HTTP字节上限限制的批次执行，逐项重新核验头部生命周期、存储revision、投影水位和活动状态，过期／非候选跳过，单条失败不阻断其他会话。永久删除使用内部维护模块，保留成功／跳过／失败和重试入口，完成后刷新诊断并清理工作台会话标记；关闭面板只停止后续批次。

缓存异常支持单条或批量重建；孤儿残留支持单条或批量清理，执行前确认永久删除不可撤销。修复由内部维护模块处理，宿主底层能力缺失时保留检测结果并禁用操作；不迁移旧插件缓存。owner RPC 严格校验类型、1–20条批次和生命周期见证，重新检测候选，拒绝非候选、过期结果及归档项目写入；官方工作区队列内再次核验活动状态、父子关系、日志revision及缓存生命周期。缓存重建完整折叠日志并等待官方缓存持久化；删除先刷盘释放闲置会话，再清理验证过的专属日志目录、溢出缓存和列表记账，拒绝符号链接及未知布局。结果保留成功／跳过／失败与错误明细，失败项可重新检测后重试；关闭面板停止后续批次，已发出的物理操作继续完成。残留大小使用宿主头部快照提供的日志字节数，未知项明确标示，不承诺包含附件或完整目录占用。当前不提供完整日志损坏、模型、网络或 Git 诊断。

开启统计时最近会话临时显示为按钮，禁用样式选择但保留用户原选择；关闭统计恢复原选择。统计点击仍打开统一「工作台概览」抽屉，并选中对应分类；会话直接打开原会话，待办直接打开详情。详情显示时隐藏统计弹窗，关闭或成功保存后恢复原统计列表、分组、搜索和滚动位置；保存失败保留详情与草稿，不切换当前项目。

统计概览主弹窗不设横向footer，右侧内容延伸至底部；左侧分类菜单独立滚动，底部以分隔线区分「关闭概览」操作，保留右上角关闭。窄屏分类移至顶部，仅保留右上角关闭。详情编辑弹窗继续提供保存、取消等必要操作。

诊断右侧内容区直接显示记录或空状态，不重复显示「分类名称 · 数量」标题及其分隔线；分类名称与数量保留在左侧导航，顶部项目诊断标题与重新检查入口保留。

统计待办页增加标题右侧「添加待办」按钮，点击打开待办创建弹窗，复用标题、描述、优先级及附件字段。默认选中当前分组项目，全项目视图默认当前活跃项目或首个活跃项目；允许选择其他活跃项目，禁止向归档／移除／合并项目添加。关闭后返回原待办统计页；保存成功更新统计列表及待办数，并保留原搜索、分组和滚动，保存失败保留输入。

统计弹窗内容区标题依次为「运行中」「近期会话」「项目待办」「项目诊断」，侧栏分类保持原有名称。

会话与待办统计右侧条目只显示标题和时间，不显示项目／文件夹名称或路径；左右保留12px内边距，长文字单行省略并提供全文提示。诊断条目使用短原因，完整session ID单独显示，可选中复制，窄屏允许换行，不截取或省略。完整原因、路径及母会话标识通过悬停提示和搜索保留，操作按钮保持固定宽度。

诊断弹窗移除顶部三张检查状态卡，说明下方用一行摘要展示检查进度、异常总数及最近检查时间；左侧保留全部异常、目录异常、列表缓存、孤儿子代理及数量。右侧无记录时居中显示主状态与辅助说明，目录分类为「目录正常／所有项目目录均可访问」。检查失败、能力不可用或检查项缺失均标为未完成，具体原因保留在摘要下方和对应分类空状态中，不以零异常冒充正常；重新检查、记录操作、清理确认及失败重试保持可用。

运行中、会话、待办三个一级分类内部按项目分组：左侧搜索项目名称或完整路径，提供全部项目及各项目数量，分组只显示项目名，路径保留在悬停提示；右侧直接显示对应记录，不重复显示分组标题、路径和总数。分组与内容之间不显示竖线，页面分类标题保留普通文字，说明文字下方显示一条完整横线，无二级菜单及主色短线。搜索框为紧凑单行，图标与输入文字左右排列并垂直居中。以项目身份区分同名项目；切换一级分类重置筛选。诊断改按「全部异常／目录异常／列表缓存／孤儿子代理／空会话」导航，四种类型始终可选，计数表示已确认异常，不以项目为分组维度。搜索异常内容、项目名、路径及会话标识；具体记录保留项目或未分组身份、路径、会话及母会话信息。空分类分别显示检查正常、能力不可用或检查未完成，不将失败伪装为正常。无匹配与无记录分别显示空态。窄面板改为上方分组、下方内容，保留原会话打开、待办定位与诊断项目跳转。

### 全局搜索

搜索可访问项目名称与目录、主会话标题与宿主允许读取的正文、待办标题与描述，包含归档与已完成内容，排除已移除、已删除或无权限记录。结果按项目／会话／待办分组，可切类型；目录命中归项目。

正文搜索仅在「全部／会话」分类且官方「历史会话搜索」实验套件`@deepseek-ai/dsh-experimental-session-search`启用并就绪时触发，搜索标题和正文，不显示依赖提示。停用、缺失或未就绪时只搜索标题；仅在官方包元数据确认套件可用且未默认隐藏时，在列表下方提示添加启用，当前默认隐藏不提示。只复用套件的隔离搜索服务，不调用或修改宿主主索引。切换到项目／待办或套件停用后取消正文请求并隐藏正文状态，卸载或重载后旧服务结果不得发布。搜索前按可访问主会话身份过滤，再由官方引擎排名及分页，首屏最多20条。

名称与标题优先，正文及备注其次；同会话聚合，摘录来自真实原文，关键词高亮。目标要求正文命中数与消息定位；当前宿主不提供时明确降级，限制见第 8 节。

点击项目进入详情，点击会话打开原会话；无法精确定位时提示。待办进入所属项目、选中待办页签、展开对应分组并高亮。打开前重查可访问性，不静默恢复归档。

`⌘K / Ctrl+K` 聚焦，方向键选择，Enter 打开，Esc 关闭并保留词。搜索词不直接过滤项目列表。加载、无匹配、失败和部分范围失败分别显示；旧响应不能覆盖新查询，失败不冒充完整无结果。

### 设置

通用配置提供「界面语言」：跟随平台（默认）、简体中文、English。优先订阅 Harness 官方 locale 服务；平台为英文时使用英文，简体中文或未支持语言使用中文兜底，宿主语言服务缺失时仍可手动选择。保存后即时生效，取消及保存失败保留原语言，跨分类切换保留语言草稿。工作台语言偏好不改写宿主全局语言；项目与会话名称、待办标题／描述、路径、附件名称及自定义模式名称／说明均保留原文。官方内置模式名称与说明在服务端确认来源后跟随工作台语言。工作台按钮、说明、计数、空状态、可访问名称、常见错误及备份恢复状态支持中英文；诊断标题分开处理用户会话名称与固定标签，恢复阻断原因逐项翻译、路径保持原文，未知宿主错误保留原始信息。官方语音、命令菜单及模型组件继续使用宿主语言与自己的字典。语言切换不重建输入会话、不清空草稿或导航状态。

Header 为唯一配置入口，一级分类依次为通用配置、外观布局、项目配置、备份恢复、其他组件。「外观布局」合并原外观配置与首页显示，包含「首页模块／统计卡片／主题配色」三个二级页签，默认首页模块；数据统计关闭时收起统计卡片页签并保留卡片与时间范围配置。主题即时预览，保存保留、取消恢复；统计开启时最近会话固定为按钮样式，关闭后恢复已选样式。每卡开关为「显示运行统计／显示会话统计／显示待办统计／显示项目诊断」，可选择 7／14／30 天统计窗口。打开设置默认进入通用配置，不再按当前选中的项目跳转到项目配置。项目配置包含「全局配置／项目配置」；全局配置提供默认项目根目录与 Agent 管理开关，项目专属配置当前展示空状态。其他组件提供「显示插件更新」开关，默认开启，保存后即时生效；检查或更新期间禁用，后台任务结束后恢复。其下提供默认关闭的「开启自动更新」子设置，随显隐开关收起但保留选择；隐藏入口不取消已开启的自动更新。每次客户端启动读取已保存配置一次，开启时自动检查并后台串行安装兼容正式新版本，不自动弹窗；重新打开更新入口可查看进度和结果。重连、切换页面、保存配置不会重复触发，开关修改下次启动生效。跨分类切换保留未保存草稿，全部分类统一保存。

插件页的刷新按钮左侧提供「一键更新」。点击后仅列出并检查当前profile用户安装的非官方插件（installed=true、availability=profile、official=false），排除宿主自带插件和未安装的官方目录项；本地包等不可在线更新的用户插件保留在「跳过更新」。仅选择兼容当前 Harness、未弃用的正式新版本。弹窗宽860px、高620px，受宿主可用空间限制；卡片列数随弹窗宽度动态调整，名称14px、版本13px、辅助12px。分为「可以更新／已是最新／跳过更新」，后两组默认折叠，展开后的插件只在各自区域独立滚动，标题和统一说明及底栏固定。手动检查完成后确认「更新全部」，开启启动自动更新时自动进入安装，逐项展示新旧版本对照和安装来源，统一说明期间插件可能短暂停止、安装失败时会保留或恢复原版本；默认安装源null与自定义源均沿用官方返回值。串行调用官方更新接口，保留各插件来源与启用状态，显示检查、移除、安装、恢复及最终结果。单项失败保留原因和安装输出，继续其他更新；传输断开导致结果未确认时停止后续更新，提示刷新核对。需重启的结果明确说明。检查或更新中可关闭弹窗，后台继续当前批次，再次进入保留进度和结果，不重复启动任务；同一窗口内工作台热重载保留批次，关闭窗口或重启客户端清空。工作台自身排在最后更新。项目诊断移除说明下方的检查状态／异常数／最近检查时间行，分类数量、空状态、错误和修复反馈保留。

自动更新的首次启动选择与批次数据在同一浏览器窗口内跨工作台热重载复用，包括启动时关闭的选择；热重载不重复检查或安装，已发出的官方请求仍记入原批次，进度、最终结果与弹窗显隐由新实例接续。卸载后未开始的步骤停止，结果未知时停止后续安装并提示核对；真正关闭窗口或重启客户端后开始新的启动周期。永久卸载后不主动启动任务，需重启生效的安装仍由用户重启 Harness。

插件更新分组互斥展开：打开一组自动收起其他组，再次点击已展开组可收起全部。安装来源单行省略，悬停保留完整来源；同一行卡片等高对齐，长来源不撑高卡片。

更新能力按官方返回字段探测：新版`update=registry`参与批量检查，旧版没有`update`时兼容`updatable=true`。`update=git`优先于旧字段，保留在跳过组并引导到官方插件页选择提交，不调用registry版本检查或安装。

通用配置提供「启动打开首页」开关，默认关闭；保存后下次启动 Harness 桌面端生效，开启时进入工作台并保留最近项目与位置，关闭时沿用宿主默认页面。普通 Web 不应用该设置；只在启动时选择一次，不覆盖配置读取期间的用户导航，不因同步或重连反复切页。旧状态缺少该字段时补为关闭，取消或保存失败不更改已保存值。侧栏入口名称与菜单位置控件右对齐且等宽，窄面板上下排列；关闭侧栏入口收起从属控件，侧栏入口与返回按钮至少保留一个。

「备份恢复」为独立一级菜单，位于「项目配置」之后、「其他组件」正上方，包含「数据备份／数据恢复／执行状态」三个二级菜单，默认选择数据备份。数据备份提供备份目录、「立即备份」和默认关闭的「启动时自动备份」；数据恢复承载归档校验、范围预览与确认；执行状态汇总备份及恢复任务状态、产物路径与备份覆盖明细。切换子分类保留表单草稿、恢复预览与后台状态订阅，并重置正文滚动位置。立即备份保存当前备份配置并启动后端任务；其余未保存设置仍为草稿。自动备份在宿主启动、主插槽与配置准备就绪后一次触发，等待启动插件更新与已知上传结束，后端继续检查会话及官方活动状态；多个窗口、重连、页面重挂载和同进程插件重载不重复触发。任务不随设置页关闭取消，退出只中断任务；最近结果可在下次启动读取，未完成产物不得当作正常备份。

「其他组件 → 终端」提供默认关闭的开关，保存后控制官方「插件 → 终端」页的配置显隐；关闭保留已保存的设置并恢复官方页面。字体／字号／配色／预览／默认Shell放在命令执行限制上方，整页只提供一个保存按钮。字体选择为集成搜索输入与下拉，用户点击时探测并请求本地字体访问权限，只展示真实已安装字体；不支持或权限拒绝保留手动输入，不以示例字体冒充本机列表。字体／字号复用官方暂存模型，留空／恢复默认后保存清除覆盖；字号10–20px，默认13px。默认Shell通过唯一真实主视图会话发现，暂存后保存为浏览器偏好，仅影响新建交互终端；无服务／会话时只禁用Shell，切换取消旧发现，不创建临时会话或终端。统一保存依次使用官方命令表单动作、字体配置、工作台配色及Shell选择；确认官方保存结果后才继续，失败或结果未知停止，保留未保存草稿，重试跳过已成功部分，不承诺跨域原子提交。离开／停用丢弃未保存草稿，保存中退出仅取消后续步骤。目录仅保留原官方`plugins.item#shell`，工作台通过`plugins.detail.section`呈现整页表单；扩展实际挂载时用限定终端详情的样式收起原表单，复用原官方状态／校验／保存动作和词典，不改注册对象或目录数据。扩展停用／卸载／渲染失败后恢复原表单；官方条目更换或其他条目取得展示权时撤下扩展。缺少`:has`能力时保留原页面，不修改官方源码或通过DOM代点保存。完整配色通过公开侧栏显示扩展实现，详见下文。

终端控件补充：所有输入与选择器统一宽度；字体直接从输入框下拉，不提供独立展开按钮。菜单与输入框等宽，字体菜单固定320px高，配色与Shell菜单按内容自适应、最高320px；超出后内部滚动，低高度受可用空间限制。预览位于字体、字号与配色之后、默认Shell之前。整页保存提供处理中、成功和失败反馈，接点失效时保留未保存草稿，不静默退出。

默认Shell的官方保存动作完成后，适配层只读核对当前浏览器的官方偏好键；存储权限拒绝、配额不足或实际值不匹配时保留草稿并提示，不能以发现列表的默认首项作为持久化成功凭据。

工作台中的开关名称统一为「终端扩展」（Terminal extensions），说明包含字体、字号、配色和默认Shell；官方「插件 → 终端」名称不变。下载是选择框左侧的辅助字号文字操作，不显示按钮边框或背景，键盘仍可操作；配色说明与下载完成状态合为一个简短段落，窄面板允许自然换行，失败提示独立显示。选择器仍与其他输入等宽。新增配色、下载、校验、预览与提示完整适配简体中文／英文，固定代码、字体名称、色值与用户数据保留原样。

终端独立配色：提供跟随平台、自定义背景／文字／光标／选区与完整16色ANSI，以及Catppuccin Latte／Frappé／Macchiato／Mocha。按钮从固定版本的官方palette仓库下载四种风格，完整校验后写入草稿；下载失败不覆盖已有配色。统一保存依次确认命令、字体、配色与Shell，各步失败停止并保留未保存部分。配色存入工作台持久化域，下载一次后可离线选择；并发保存按原色板校验，拒绝覆盖其他窗口修改。选择时只改变页内预览，保存后即时更新已有侧栏终端。官方无完整palette接口时，仅替换公开侧栏显示插槽的渲染，继续复用官方TerminalView连接、输入、控制权、流确认、回放和生命周期，不伪造输出或向Shell发送配色命令。关闭开关或跟随平台恢复官方显示；不另建终端目录或会话，官方入口消失时撤下显示适配。

配色显示切换保留薄适配，停用或跟随平台时实际渲染原官方组件。两种组件均通过公开TerminalView挂载；已结束／失败且宿主仍保留的终端在重新挂载时调用公开connect取得完整screen快照，不用最后一帧增量拼接历史，不创建或重启Shell。宿主已清理终端时沿用官方不可用反馈，不伪造已丢弃画面。

备份以 age 加密归档，临时副本权限受限；首次在 DSH 数据目录生成独立恢复密钥，不放入归档。校验解密内容、清单及每个文件摘要后才发布正式文件。目的目录不得与任意已发现源根重叠；历史清理仅按下述保留期限执行。覆盖结果逐项显示已校验、观察副本、未发现、未覆盖或导出失败。会话导出固定连续事件前缀及 fork 继承长度，SQLite 使用在线 backup 并验证；运行中的普通文件只声明观察副本。不同数据源不构成全局一致恢复点，客户端 LevelDB、自定义附件根、远端对象及跨源附件引用未完整适配。

备份文件名采用本地日期、秒级时间和8位标识，如 `dsh-20261110-180426-5b1ac6a1.tar.age`，回滚副本加 `rollback` 标记；发布时禁止覆盖同名归档。经用户要求，可将旧长名归档实际改名，先核对摘要且禁止覆盖已有文件。恢复使用单一只读选择框，点击框体直接下拉，无需输入路径；选项显示真实文件名、类型、时间和大小，选中后框内显示文件名，完整路径作为选择值及悬停提示。展开刷新最近列表，支持键盘和面板内定位；最大高度320px，超出后内部滚动，小窗口按可用空间缩小。

备份保留期限支持7、14、30天和永久，默认永久。设置保存后，仅在新备份发布成功后清理超过期限的普通备份；删除前解密、校验清单和文件摘要，并核对清单时间及文件未变化。回滚副本、外部文件、符号链接、无法校验或清理的归档保留。备份失败不触发清理，恢复保留当前环境的保留期限配置。

恢复入口展示最近 30 个备份及回滚副本，直接点击选择；页面不提供恢复密钥路径输入，自动使用当前宿主密钥。「数据备份」显示密钥位置，说明首次备份时生成、密钥不在归档内且须单独保管；已读取到实际路径时显示实际路径，否则说明DSH数据目录下的默认位置。底层接口仍支持指定外部密钥，使用不同密钥的备份无法通过当前页面恢复。先解密、扫描清单、校验逐文件摘要，再展示时间、文件大小、项目与待办数量和覆盖范围。恢复范围用统一下拉菜单提供「恢复到独立目录」「恢复工作台状态」，每项展示范围与效果说明。预览有效15分钟，选择范围并填写必要目录后点击「开始恢复」执行，无需额外勾选确认开关；切换范围不自动执行。取消、过期或重启后须重新预览。恢复与备份互斥，任务不随关闭设置取消。

「替换当前工作台状态」只通过正式存储 API 恢复项目关联、待办、个人标记与偏好。活跃项目按目录匹配当前宿主，工作树会话关联必须可核实；归属不完整或预览后 revision 改变时拒绝替换。写入前保存并回读校验加密回滚副本，写入部分失败则尝试恢复原状态，自动回滚失败时明确展示保留副本路径。保留当前备份配置并关闭插件自动更新；恢复过程中暂停保存设置，成功后关闭旧草稿并刷新工作台。

「完整归档恢复到独立目录」在所选安全目录内新建恢复目录，复制完成后再次校验再发布，不覆盖已有文件或重建归档链接。会话、附件、SQLite、Profile 等宿主数据暂不原位激活；需要宿主统一维护及事务能力后再实现。观察副本的摘要校验不等于业务一致性验证。

侧栏位置提供「顺序第 1／2／3 个」和「倒序第 1／2／3 个」，顺序从顶部数、倒序从底部数；根据宿主当前入口动态计算排序权重，其他插件加载或卸载后重新定位。入口不足时顺序放在末尾、倒序放在最前。旧第 4–9 个配置兼容为顺序第 3 个。相同排序权重的其他入口仍遵循宿主稳定排序。

选择型下拉菜单共用宽度规则：简短选项跟随触发控件，最小 140px、最大 360px；带说明的项目、模式和模型菜单统一 360px。实际宽度不超过当前弹窗、工作台及视口交集，内留 8px。设置位置、统计范围及最近会话样式共用该规则。

主题有跟随 DSH、DSH 默认、清爽、温暖阅读、紫晶工作台。明暗跟随宿主，工作台不设独立明暗配置。设置选择即时预览，保存保留，取消恢复；未确认预览不写入其他操作的保存。

保存统一提交全部分类，成功才生效；失败保留草稿并回滚，支持重试。立即备份按钮独立保存备份配置后执行任务。全局 Agent 配置不依赖当前项目可写性，归档项目的业务只读规则不变。根目录错误引导对应字段，Esc 关闭并恢复入口焦点。

## 7. 一致性与体验

- 宿主工作区名称、会话及归档为权威；插件保存身份绑定、待办、项目权限与个人偏好，不复制整份会话历史。
- 同步失败保留成功快照，标明可能过期及最近成功时间，提供刷新。当前实现订阅更新、窗口聚焦刷新，并在可见状态每 15 秒补充刷新。
- 任何创建、编辑、状态变更、设置或布局操作只在持久化成功后反馈成功。提交成功但刷新失败需区分提示，不能把已提交操作误报为未保存。
- 工作台 Toast 统一显示在顶部中央，背景和状态图标适配每个主题的明暗外观。文案明确操作结果，受限操作给出下一步；成功提示短暂显示，较长信息保留足够阅读时间，并可手动关闭。提示不抢夺键盘焦点，也不占用页面布局。
- 列表和宫格数据与统计一致，详情两栏标题和工具行对齐。长名称、路径、标题省略时提供全文查看，数据本身不截断。
- 默认会话／待办 65:35，保存比例范围 40–70%，已有比例保留；850px 及以下为页签。低高度和软键盘按可用视口降级，不把操作挤出屏幕。
- 菜单、标签、弹窗和抽屉支持键盘；焦点可见，关闭恢复触发器。主题、分组和布局切换保留草稿与滚动。
- 实现严格对照已确认的 HTML 原型、SVG 图标和 CSS，不以修改设计稿迁就实现。测试与视觉验收范围分开记录。

## 8. 宿主限制与保留需求

以下需求仍有效，Harness `0.2.2-rc.1` 公开接口暂不足以完成；界面不得模拟已成功执行。

| 能力 | 目标行为与当前限制 |
| --- | --- |
| 项目归档／恢复 | 0.2.14 起由插件实现：归档后业务只读且可恢复，个人标记可改；会话锁定归档时的状态，不能单独归档或重命名新建；宿主原生归档接口仍缺失，宿主自身视图不感知 |
| 修改目录与项目迁移 | 选择目标目录、预览、确认；当前无安全的绑定目录更新或跨项目迁移接口 |
| 迁移撤销 | 自成功起 72 小时内按批次撤销；没有真实迁移前不得生成已完成记录 |
| 会话永久删除 | 二次确认后由工作台内部维护模块处理；仅适配官方 JSONL 专属目录，缺少宿主底层能力时明确拒绝 |
| 正文搜索 | 官方实验套件启用且就绪时搜索标题和正文，无依赖提示；停用只搜标题，仅套件可用且未默认隐藏时提示；不使用或修改宿主主索引 |
| 命中数与消息定位 | 当前正文搜索最多返回 20 条，不提供命中数及精确消息定位；按实际结果提示 |

迁移目标未关联时，保留原身份、名称、全部会话／待办及设置，只更新宿主绑定目录；目标已关联时迁入目标，保留目标名称、目录与设置，源身份保留迁出去向。会话原执行目录和日志不随迁移改写。

迁移预览包括身份与目录、全部会话／归档数量、待处理／已完成数量及设置保留规则，确认前重查。运行中、归档、不可写、相同目录、目标已移除、目录占用、身份内容冲突和未结束的可撤销迁移应阻止写入。同 ID 同内容去重并保存原关联，不同 ID 同标题全部保留。

迁移和撤销必须原子提交，失败完整回滚。更新目录的撤销仅恢复旧目录，保留新数据和当前设置；迁入已有项目的撤销按批次恢复源数据及后续编辑和源设置，目标原有／新增内容保留，已删除记录不复活。保存类型、源／目标、原／新目录、实体关联、设置、完成与截止时间；到期只读，不再撤销。旧合并记录保持原期限的兼容读取。

## 10. 技能、MCP 与 RSS 扩展

用户已确认在工作台内直接管理三类能力，功能参考 `dsh-skills-manager-master`、`dsh-mcp-connector-main`、`dsh-rss-master`。本节统一定义功能、数据归属和宿主限制；正式插件接入状态见开发日志。

统计设置提供运行中、会话、待办、诊断、技能、MCP、RSS七项，最多启用六项。尝试开启第七项时提示「最多显示 6 张统计卡，请先关闭一项」，保留原选择，不自动替换。原四项偏好保留，新项默认关闭。足够宽时单行最多六张，随区域宽度缩小依次三列、两列、单列。

技能二级菜单为全局技能、项目技能、技能来源、技能市场、回收站；全局技能按技能来源分组，项目技能按项目分组。技能来源只展示本地目录，可启停、添加路径，不展示目录内具体技能；技能市场和回收站不分组。技能标题按钮固定为「添加技能」。移除可写技能先进入回收站，恢复保留原作用域、来源与启用设置；同名冲突阻止恢复，永久删除需明确确认。

MCP二级菜单为我的连接、MCP市场、市场来源；我的连接按已启用、已停用分组，连接成功、需授权和失败作为记录状态；MCP市场按分类分组，市场来源不分组。MCP标题按钮固定为「添加链接」，市场来源支持添加、编辑及启停。工具管理放在连接详情中。

RSS二级菜单为「我的订阅／推荐订阅源／导入与导出」，标题按钮固定「添加订阅」。我的订阅按自定义分组展示，支持添加、重命名和移除分组，移除分组保留订阅并转入「未分组」；新增及编辑订阅可选择分组。添加入口位于「自定义分组」标题右侧，选中分组后显示编辑入口；窄面板同样可达。列表顶部移除刷新及设置按钮，单订阅详情保留刷新。推荐订阅源提供搜索、预览和添加，不分组；导入与导出页集中提供OPML导入预览、去重和导出，导入候选展示分组，导出包含自定义分组。文章通过订阅详情阅读，不另占二级菜单。

三类管理中的内容统一以卡片网格展示，包括技能、来源、市场、回收站、MCP连接和RSS订阅；卡片只呈现图标、名称、一行简短说明及一个常显操作。启用／关闭使用开关，直接复用设置页开关的视觉与键盘交互；市场未添加记录提供「添加」文字按钮，已添加记录使用启停开关；回收站提供「恢复」。不展示地址／路径、工具数、检查时间和重复状态徽标，异常仅显示紧凑提示图标，完整信息放在详情。操作单独响应并保留焦点，卡片其他区域点击进入新的详情／配置弹窗。详情弹窗采用顶部返回与关闭、左侧分区菜单、右侧正文和固定底部操作，沿用连接器中心的配置与状态操作衔接；不打开浏览器新窗口。底层管理弹窗保留原菜单、分组、搜索与滚动且暂不可交互；返回或关闭详情后恢复列表状态和焦点。详情进入编辑后取消回到详情并保留草稿；技能与RSS保存返回原列表，MCP保存留在详情或继续授权。关闭详情及切换分组／菜单保留编辑草稿，刷新、确认删除、OAuth演示和文章阅读在详情弹窗内完成。

技能管理包括全局／项目、正文、导入、编辑及启停；MCP管理包括HTTP／stdio、认证、连接、工具与作用域；RSS管理包括分类订阅、文章预览、OPML和刷新。原型中的文件、授权、连接及抓取操作只演示交互，不视为宿主能力已经交付。

### 10.1 摘要、加载与页面记忆

| 入口 | 主数字 | 辅助信息与计数边界 |
| --- | --- | --- |
| 技能 | 全局有效且已启用的去重技能数 | 项目技能数及异常数；项目技能不累加为全局可用技能，同名来源不重复计数 |
| MCP | 实际已连接的受管连接数 | 配置总数及异常数；连接中、未知、需授权、已停用均不计为已连接 |
| RSS | 订阅源总数 | 检查失败数及最近刷新时间；增量游标不作为未读标记 |

首页先显示已有摘要，初次读取显示加载状态，不用0代替未知。单模块读取失败只影响自身，读取首页不触发RSS抓取，也不等待MCP建连。设置保存时同样校验六卡上限；超限拒绝保存并保留草稿。

首次进入使用各入口的默认二级菜单；之后分别记忆菜单、分组、筛选、搜索和滚动。无分组页不显示分组栏或窄屏分组选择器。技能、MCP、RSS均提供「导入与导出」二级菜单，移除列表工具栏及操作卡片上的导入／导出按钮，改由菜单行进入导入预览和导出流程。技能导出JSON记录名称、说明、正文、原作用域及启用状态，不打包关联文件；原型支持将该JSON导入所选目标作用域，同名候选跳过。RSS定时刷新设置属于「我的订阅」，MCP注入策略属于连接详情，技能导入目标在导入流程选择。

有分组的扩展页面与运行中／会话布局保持一致，搜索框放在左侧分组上方，分组与卡片内容之间不显示竖线。无分组时搜索保留在内容工具栏；窄面板按搜索、分组选择器、卡片内容顺序排列，不创建重复搜索框。搜索与分组仍共同筛选记录，并保留原页面状态。

### 10.2 技能

全局与项目技能分别管理名称、说明、路径、来源、启用状态、分类、同名冲突及解析异常，详情包含正文和关联文件。分类为编辑字段，不设置独立分类管理页。自定义来源由用户明确登记，不扫描整个磁盘。

DSH、公共Agent及已注册项目内的可写技能允许创建、编辑、移入回收站；第三方来源默认只读，启停采用工作台策略，不修改第三方文件。来源开关与单技能开关共同决定是否生效。按宿主优先级选择同名有效技能，保留其他来源供解释；禁用后不能被更近的原生提供器重新暴露，当前和后续Agent的技能列表均需更新。

导入支持本地目录、文件和仓库地址，依次选择源、全局／项目目标、候选与冲突处理；同名时明确跳过或替换，替换前保留可恢复副本。归档限制总大小、文件数及解包范围，拒绝穿越和越界链接；具体阈值在能力接入时确定，不以演示值作为产品限制。

保存后刷新目录和宿主技能菜单，分别反馈「文件已保存」与「技能已生效」；刷新失败不能把已保存文件误报为保存失败。项目作用域只接受已注册项目，不接受任意工作目录。回收站记录不参与有效技能统计，恢复回到原作用域、来源与启用设置；同名冲突阻止恢复，永久删除明确确认。

与已有技能管理器共存时，文件可共享读取，启停策略只有一个权威。展示策略归属，未接管记录只读；接管前预览策略与归属变化，不静默安装、停用原插件或改写其策略文件。

### 10.3 MCP

连接支持新增、编辑、重命名、启停、重连、移除、搜索、全局／项目作用域与诊断。详情显示工具名称、说明、参数结构及单工具开关，提供JSON配置导入和脱敏导出。

UI参考连接器中心实际详情交互：市场先预览名称、说明和连接要求，再点击「配置并连接」；连接详情默认折叠工具列表，展开后支持名称／说明搜索及逐工具参数展开。工具开关变更保留搜索、滚动与当前焦点，连接不可用时禁用开关并说明原因。主按钮按状态提供启用、重新授权、重新连接或查看工具，处理中禁用重复操作。MCP配置保存后留在详情，首次OAuth配置继续进入等待授权页；取消授权保留配置，成功后展示发现的工具，返回列表仍恢复原市场或连接列表位置。原型仅模拟授权和连接，真实外部授权页由OAuth协议要求决定。

| 连接方式 | 配置与认证 |
| --- | --- |
| HTTP | 地址、请求头；无认证、Bearer、API Key或OAuth |
| stdio | 命令、参数、环境变量及工作目录；敏感值按凭据规则保存 |
| OAuth流程 | 打开授权页、等待回调、取消、刷新令牌、重新授权；打开页面不代表连接成功 |

工作台通过宿主官方MCP客户端管理自己的条目，条目身份和工具前缀稳定；重命名只改显示名称。启用后以实际运行状态、握手与工具发现作为成功证据，分别展示连接中、未知、已连接、需授权及失败；握手、工具发现、授权、网络和进程启动错误分别提示。停用与移除仅影响工作台拥有的条目，配置失败保留旧记录和可恢复配置。

注入策略包括按项目可见、单工具开关、始终注入及按会话启用。宿主不支持按会话隔离时禁用对应选项并说明，不模拟成功。官方客户端缺失时只禁用建连，不阻止工作台启动，也不自动安装其他插件。

连接、授权和刷新由后台任务持有，关闭面板继续；超时、取消与插件卸载释放本模块的监听及进程资源。凭据保存到宿主支持的凭据存储，摘要、Agent输出及导出不返回秘密；普通编辑保留已有密钥，清除需明确操作。恢复配置不等于恢复远端OAuth授权，恢复后重新握手。

其他插件拥有的连接显示来源及只读状态，不重复建连或抢占条目。接管先预览配置与归属变化，不默认停用或删除原插件。市场按分类、关键词浏览候选，填写配置后添加；市场失败时仍可手工新增，市场来源仅加载目录描述，不自动连接服务。

### 10.4 RSS

订阅支持增删改、自定义分组、搜索、检查、单源与批量刷新。记录包含名称、URL、分类、启用状态、检查时间和错误，按规范化URL去重；编辑不重建身份。移除分组将订阅移入「未分组」，不删除订阅；重命名同步成员。

OPML导入先预览候选及分组，报告新增、重复、无效数量，不静默覆盖现有分类和名称；确认时登记所选候选的分组，导出包含自定义分组与订阅。推荐来源保留出处，用户预览并选择目标分组后才订阅，不默认添加任何来源。

订阅详情显示RSS／Atom文章标题、来源、发布时间、摘要，支持搜索当前缓存、工作台内预览及打开原文。外部HTML清理后展示，仅允许安全链接，不运行远端脚本或自动加载外部图片；只有摘要时明确说明，不冒充完整正文。缓存读取不修改已读状态。

订阅配置持久保存，文章缓存独立保存并限制条数及容量，具体阈值待正式接入确定。抓取限制并发、超时和响应体，支持取消并逐跳检查重定向；默认拒绝回环、私网和保留地址。用户明确开启可信内网源时单独标识。

手动刷新与可配置定时刷新在后台执行，定时仅处理启用源，关闭面板不中断。单源失败保留旧文章并报告原因，不清空缓存；旧抓取结果不能覆盖URL已修改的订阅，并发编辑按版本校验。

Agent可读取订阅、检索文章、读取单源及增量内容；增量游标按调用作用域保存，与阅读状态分开。修改订阅、导出文件遵循宿主审批与工作区边界，待办管理授权不扩展为其他模块授权。工具采用 `workbase_` 前缀。工作台订阅独立归属，可通过OPML预览导入原插件数据，不静默修改原订阅或游标文件。

### 10.5 共用权限与恢复

管理操作限宿主owner，分别判断读取、写入、凭据和工具注入能力。长任务具有可回读的任务状态，处理中禁止重复提交，失败保留草稿。追加配置保留既有项目、会话与待办身份；技能正文、文章缓存与MCP运行状态不混入工作台业务状态，也不把上次「已连接」当作当前状态。

备份范围纳入模块配置、凭据引用及需要归档的技能目录。恢复遵循第11节，先验证、保留加密回滚再替换；文章缓存可重建，MCP必须重新握手。完整网络、OAuth及工具注入效果需要真实宿主能力，原型只展示模拟流程。

## 11. 备份恢复的数据范围与边界

设置入口、触发时机、保留期限、密钥、文件选择和两种恢复流程统一见第6节「设置」。本节补充覆盖口径与失败边界。现行方案为前端触发、后端在线执行；独立CLI、停机快照、退出时完整备份、`.dshbackup`格式及反复输入口令的早期方案已废弃，不作为当前功能要求。

### 11.1 数据范围

备份覆盖DSH核心数据、关联Profile、已适配插件及已明确纳入的外部数据根，不能把仅复制 `storages` 或DSH主目录称为完整备份。实际范围按当前宿主、后端和配置发现，不把某次盘点的路径、版本或数量作为运行常量；同一数据根被多个Profile使用时记录共享关系，不能因只选desktop入口就忽略共享数据。

| 数据类别 | 覆盖要求与恢复边界 |
| --- | --- |
| 会话与Workspace | 保存全部历史generation、父子／fork关系、成员、顺序、置顶及归档；不把运行锁恢复为活跃状态 |
| Workbase与归档插件 | 保存项目绑定、待办、个人标记、偏好和归档专有状态；旧Workbase域只作迁移资料，不覆盖现行域 |
| 图片、文件与名称引用 | 保存原始持久对象及名称／硬链接关系，核对摘要和会话引用；未适配的自定义根与远端对象明确未覆盖 |
| Profile与插件环境 | 保存配置、精确版本、安装来源、锁文件、启用状态及市场持久状态；包载荷与native兼容性未验证时不承诺离线环境可恢复 |
| 凭据、配对与历史配置 | 一律作为敏感内容进入加密归档，密钥本身除外；恢复不自动激活设备身份、旧更新事务或其他自动任务 |
| 技能 | 保存管理策略、来源、仓库记录、回收站和已纳入技能；公共／项目外根明确登记，链接不扩大为整个项目源码 |
| billion-context | 独立发现XDG／BILI配置、SQLite、历史、CA、持久映射和状态；日志、缓存、租约分开分类，不把整个外部根当缓存 |
| TUI与桌宠 | 保存历史、偏好、恢复游标、副作用记录、配置及自定义资源；不自动重放副作用，不将历史JSON当当前运行状态 |
| 客户端记忆 | 按对应客户端白名单结构化导出；不整体复制运行中LevelDB、Cookies或Session Storage，未接入时明确未覆盖 |
| 未分类与缓存 | task-board、skin-center及旧回收站等先保留为隔离观察资料，确认所有者与重建能力后才允许激活或排除 |
| 项目源码、真实worktree与外部引用目标 | 不自动纳入；保留登记与路径存在性说明，恢复项目记录不表示目录内容已恢复 |

已确认可再生的附件请求缓存、运行锁、node_modules及Git目录按现行规则排除；其他名字含“cache”或“lock”的文件不能仅凭名字丢弃。普通文件读取期间发生变化时报告该范围失败；符号链接仅记录、不跟随，硬链接记录内容和关系。SQLite采用在线备份并在副本验证，不直接复制活跃db／wal／shm组合或修改源库。

### 11.2 覆盖结果与一致性

| 结果 | 可向用户声明的保证 |
| --- | --- |
| 已校验 | 对应适配器范围的文件、结构或读取边界已通过；不能推广为全局同一时点恢复点 |
| 观察副本 | 字节及摘要可验证，缺少业务一致性保证 |
| 未发现 | 当前已解析范围不存在／尚未物化；与无法解析路径不同 |
| 未覆盖 | 后端、客户端、外部对象或关联能力未适配，说明原因 |
| 导出失败 | 范围变化、读取、空间或校验错误；不得静默跳过 |

清单记录格式版本、备份标识、创建时间、宿主与插件版本、Profile和共享关系、纳入／排除／未覆盖范围、逐文件相对路径／大小／摘要／权限，以及各源导出时间区间。归档回读校验、数据覆盖、离线环境可用和真实恢复通过是不同结果，不能合并为一个“完整成功”。

会话必须取得持久化屏障和稳定连续读取边界，不能只等待文件大小不变；附件核对持久对象及引用；结构化状态记录版本和导出时点。能力缺失显示明确原因，不强杀宿主、停止其他客户端或降低自动任务的校验门槛。当前客户端LevelDB、自定义附件根、远端对象、跨源附件引用和全量原位激活仍有边界，具体实现状态由开发日志维护。

### 11.3 安全、失败与恢复边界

归档内容只指定受控相对路径，不能指定任意本机覆盖目标。恢复解密到私有暂存区，拒绝绝对路径、目录穿越、重复冲突项、符号链接越界及设备等特殊条目；限制文件数与解包总大小，按目标卷预检空间，具体上限由正式能力确定。

只有owner可发起备份、预览与恢复，不向Agent开放覆盖当前状态或读取凭据的工具。前端不提交任意shell指令；临时明文、密钥和恢复日志限制为当前用户可访问，凭据不进入普通进度日志或客户端结果。

目录不可写、磁盘满、密钥损坏／权限异常、错误密钥、摘要损坏、版本不兼容、归属冲突和任务中断分别提示原因。加密失败不生成明文替代品；校验失败不发布正式归档；未完成载荷不能作为正常备份恢复，失败不触发历史清理。

恢复兼容性在写入前核对，不能把较新格式直接降级；旧格式须有受支持的迁移链。预览只读，确认时重新核对归档身份、摘要、当前归属及revision；取消、过期、重启或数据变化后重新预览。

工作台替换先生成并回读验证加密回滚副本、记录恢复步骤，然后通过正式存储接口提交；副本失败不替换。部分写入失败尝试恢复原状态；自动回滚失败保留全部副本并明确路径与故障，不能误报成功。回滚副本不随普通保留期限清理。

完整归档只在用户所选安全目录下发布新的恢复目录，先复制、复验再发布；失败清理本次未发布目录，不覆盖现行数据或重建外部链接。后续若开放全量原位恢复，须先具备所有写入者的维护能力、多根事务日志、异常退出恢复及受控启动验证；多目录rename本身不构成全局原子事务。

恢复历史不撤销工具已产生的文件修改、部署或其他外部副作用，也不自动续跑未完成任务。尚未适配的身份、scheduler、市场更新和副作用记录保留在隔离资料中，不自动激活；项目目录缺失保留登记并显示不可用。
