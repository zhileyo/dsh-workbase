# DSH Workbase · UI 设计规范

更新日期：2026-11-22。共用规则集中在第 0 节；后续章节只补充具体场景。需求统一见 [PRD](PRD.md)，所有HTML演示集中在 [ui-directions.html](ui/ui-directions.html)，实际实现与验证范围见 [开发日志](../.agents/notes/dev-log.md)。

## 0. 共用一致性规则

概览的运行中与待办页保留分组区上方标题，右侧列表分别显示“运行中会话”和“待办列表”，复用`stats-page-heading`，标题不随列表滚动。RSS订阅标题下使用共用`integration-caption`说明用途，在“我的订阅”和“推荐订阅”中保持一致。

项目迁移及记录从首页和详情的项目菜单进入共享抽屉。迁移单页显示当前项目名称，目标复用Picker按项目名称选择，不输入目录；同名选项用路径辅助区分。选择后在下方自动显示迁出内容与目标现有内容，会话及待办分四项呈现，复用现有统计字号和卡片边框；页脚“确认迁移”直接提交，无二次预览页。切换目标释放旧令牌并丢弃迟到结果，错误保留选择并可重试预览。确认结果不明时禁止重复提交，成功回执核验后刷新并关闭，源项目从工作台移出，记录在目标项目菜单查看。记录详情共用ModalFlow，返回保留滚动及入口焦点。迁入已有项目已接持久执行接口，预检失败禁用确认；未关联目录仍缺执行能力。记录为空时说明预览不产生记录。撤销期限与可操作状态按服务端读取结果展示；点击“撤销迁移”直接执行本批撤销，验证reverted回执后恢复源项目显示、刷新并关闭，忙时禁用关闭和返回，未知结果不重复提交。

迁移抽屉的正文使用共用设置页内边距（桌面24px／28px、650px及以下20px／18px），正文独立滚动，页脚复用固定dialog-footer。单页内容最大860px居中，当前项目与目标选择同排等高，650px及以下纵排。迁移预览用四行对照表，列为内容／迁出／目标现有／迁移后；结果按实体ID去重，零值使用次要颜色，沿用12px说明及13px正文规格。旧身份预览统计仍保持等宽两列，不套用普通元数据定义列表的80px标签列。宿主能力缺失及已核实的源目录不存在使用信息说明，目录路径可查看；真正的身份、权限或运行中会话阻断仍显示错误。预览内容再长，取消和确认仍留在页脚。

### 0.1 开发与维护入口

设置辅助说明使用简短句子，保留用途、适用范围、生效时间、停用结果及恢复边界；不重复标题或冗长操作步骤。权限说明明确关闭后仅可查询，初始化说明明确保留已有文件，密钥说明明确单独保管；字段上限、异常及保存状态按实际情况保留。正式组件、原型与英文词典同步维护。

私人订制的四个菜单不显示档案目录和重复的正常生效说明；生效范围及时间合并到分区介绍，提示词服务未就绪时继续显示提示。备份页保留实际密钥路径，说明集中为加密、密钥单独保管及未覆盖范围；运行中文件不保证一致性，以用户能理解的措辞替代「观察副本」，完整覆盖结果仍在执行状态中查看。

通用组件中的更新入口开关统一命名「插件更新」，移除标题及读屏名称中的「显示」；说明文字仍解释入口位置，开启自动更新沿用既有子设置。

主题选择卡片仅显示单选控件与主题名称，移除「经典湛蓝／跟随平台」卡片内的说明小字，五个选项采用相同内容结构；名称已表达用途，避免重复说明占用卡片高度。页面级明暗切换提示及即时预览说明仍按既有规则呈现。

设置一级菜单固定为「通用配置／外观布局／项目配置／私人订制／扩展配置／其他组件／备份恢复」，备份恢复置底。扩展配置二级菜单统一命名「技能／连接器／订阅」。三个管理页标题动作区均提供36px共享设置图标，分别标注「技能设置／连接器设置／订阅设置」，直接进入对应全局配置页；正式组件共用概览外层抽屉，返回保留管理内容、筛选、滚动与焦点，配置仍统一保存。旧版停用目录移至「技能管理 → 技能来源」，仅存在已登记且未删除的历史中转安装时显示，复用来源记录与打开目录按钮。

「其他组件」默认进入「通用组件」二级页签，原插件更新与终端扩展设置集中在该页。语音播报移入同组二级菜单；通用组件中的「语音播报」开关默认关闭，开启草稿时显示语音页签，保存后启用会话喇叭入口，关闭时隐藏页签并回到通用组件。组件启用与自动播报分别配置；停用停止音频、释放会话正文索引及配置轮询，保留已保存的服务配置与密钥。二级导航复用SettingsSubtabs，键盘导航跳过隐藏页签，切换保留草稿；停用组件时不提交隐藏语音页的未完成草稿。

语音二级页按用户指定精简：不重复页签标题，不显示顶部服务介绍、官方播报限制说明、底部保存／重播提示及「清除已保存密钥」开关；直接显示配置项，保留自动播报与Markdown过滤说明、密钥占位提示及实际加载／异常状态。这是分区标题与介绍保留规则的明确例外。

语音播报入口统一使用视觉真源的喇叭路径；宿主当前没有公开喇叭图标时复用工作台共享`Icon`。顶部关闭时显示`speaker-off`（喇叭加叉），启用时显示`speaker`（喇叭加声波），同时通过底色与`aria-pressed`表达开关状态。当前会话播放时，顶部及正在重播的回复显示循环声波动画；回复按钮仍执行停止播报。停止后恢复静态，系统要求减少动态效果时禁用动画。宿主插槽中的声波动画由`styles.css`适配，不依赖工作台根作用域。

工作台界面统一将MCP称为「连接器」，英文为Connectors；导航、管理标题、市场、配置、导入导出、无障碍标签及已知异常说明同步。代码模块名、配置键、凭据引用、协议字段和用户服务名称保留原值，不参与文案替换。

概览分类导航按「运行中 → 近期会话 → 待办 → 诊断 → 技能 → 订阅 → 连接器」排列，RSS菜单显示「订阅」，英文为Subscriptions；键盘导航沿用相同顺序。

多语言共用同一组件、尺寸、字体角色和面板断点，不新增语言专属密度。工作台根节点声明实际语言；一级设置导航使用简洁单行名称（英文外观布局为 Appearance），二级页签和说明允许断行，操作名称保持完整。顶栏搜索在品牌、同步状态和操作按钮之间弹性分配剩余宽度，按控件实际宽度避让，不以固定左右预留宽度绝对定位。界面文字按源码静态文案与模板参数翻译，用户标题、正文、文件名、路径与自定义模式名称／说明保留原值。服务端确认由工作台补充的官方内置模式名称与说明跟随工作台语言，快捷输入与待办菜单共用翻译入口；不按模式ID或名称猜测自定义文案。日期及相对时间按实际工作台语言显示。设置中的语言选择沿用 Picker，与同排控件等高；统一保存生效，取消保留原语言。HTML 原型展示配置入口与布局基线，原型不连接宿主语言服务，不代表真实语言切换已经验收。

**待更新**：顶栏弹性搜索目标尚未同步真源；现行751px以上仍绝对居中（`ui-directions.html:1209–1211`）。

新增或调整界面先查本节，再查对应场景；同类控件复用已有组件和共享样式。共用规则只在本节维护，其他章节引用，不复制另一份尺寸表。新例外必须说明使用场景和理由，同时修改本节、视觉真源及相关组件；未确认的独立原型不能覆盖正式基线。

已确认的设计统一维护在PRD、本规范与`docs/ui/ui-directions.html`；侧栏入口讨论稿和RSS独立方案已归档，不再保留并行设计入口。方案取舍及验证边界见开发日志，历史讨论中的现状不代表当前产品状态。

技能、连接器及RSS管理面板的扫描／刷新、保存、启停、导入与导出结果共用工作台顶部Toast，沿用第6节的样式、时限与礼貌播报，不在列表上方新增操作结果行。技能与连接器保存及来源操作失败也使用信息Toast，保留输入；成功后刷新失败明确说明操作已完成，不自动重试写入。加载进度留在按钮及对应区域；读取失败、宿主能力缺失、字段校验、授权待完成及条目异常持续显示。连接器配置读取失败停止加载占位，恢复读取后自动清除错误；相同轮询错误仅首次Toast，不重复加载市场或展示同一读取错误。部分成功以信息Toast简述，失败项与凭据清理未确认原因保留在原区域。RSS取消订阅继续显示30秒撤销入口，不缩短为普通成功提示时限。

运行／会话／待办／诊断／技能／连接器／RSS之间切换只替换概览内容，共用持续挂载的外层Modal，不重新创建遮罩或重播抽屉入场动画。技能、连接器及RSS的添加、详情、编辑、授权与文章阅读同样复用该外层，只替换标题、返回按钮与内容；列表节点隐藏并保留，返回恢复筛选、滚动及原入口焦点。项目规则的添加及详情也复用设置外层，返回恢复设置草稿和列表状态。待办详情与诊断删除确认按各自既有尺寸保留独立弹窗。保存状态及当前页关闭动作交给共享外层处理。同一客户端连接重新进入已读取的管理页时先复用上次快照，后台读取不清空现有内容；缓存只在当前连接内存保存，连接与模块分别隔离，不写入页面偏好。菜单切换后恢复当前菜单焦点，不重新聚焦搜索框。

外层工作台面板宽度与弹窗内容宽度分别响应：原型媒体宽度断点在构建时映射到`workbase`，原型原生弹窗容器查询映射到`workbase-dialog`；抽屉只提供后一个名称，根节点提供两个名称作为无弹窗时的回退。扩展详情原型与正式`Modal`共用72px标题栏、24px横向内边距及20px／28px标题，标题字体沿用主题的`--font-heading`，不得被通用分区h3规则覆盖；返回及关闭沿用共用`IconButton`的29px×29px、5px内边距。外层面板650px及以下为60px标题栏、18px横向内边距。不能通过位置偏移补偿不同标题栏或容器语义。

扩展字段统一复用`FormField`及原型`.field`标签间距，不叠加通用弹窗`label`的外边距。RSS创建／编辑按订阅名称、分组、全宽订阅地址排列；启停沿用来源菜单。可信内网源选项只在已配置为可信、输入明显的本机／内网地址或抓取报告私网限制时显示；该例外用于让用户对实际地址作出明确选择，空白及普通公网表单保持设计稿布局。地址验证始终由后台逐跳校验，界面的显示条件不替代验证。

技能创建、编辑与市场添加共用服务端名称规则。非空非法名称立即在原帮助文字位置显示字段错误并关联aria-invalid／aria-describedby，保存按钮禁用；Enter提交仍先校验并聚焦名称，不向后端发送非法名称。改为合法名称恢复帮助文字及保存条件，草稿、范围和安装位置保留。

项目详情的Harness右栏入口采用官方控件例外：沿用官方`ExpandButton`的`Button size="sm"`（28px点击区域、官方小圆角，当前8px）、15px镜像`IconPanelLeftOutlineRegular`、宿主次级文字色及官方Tooltip，不套工作台36px工具按钮或主题强调色。理由是该入口属于宿主窗口工具，与官方会话页保持一致。位置为全局顶栏最右、工作台设置之后，16px短竖线两侧各8px；主页不显示，详情只在已有未归档、归属及有效目录匹配的可用会话存在时显示入口，无可用会话时按钮与分隔符一起隐藏，不显示创建提示或新建入口。进入详情只读检查目录，不持有会话、不自动展开；点击后才复用项目已有会话，优先本次插件生命周期内上次成功目标，否则最近可用会话，等待时禁用，成功直接展开，失败可重试，不创建空会话。会话新增后入口自动出现；目标删除、归档或目录变化立即收起并重新判断，其他候选不自动打开。桌面展开后入口及分隔符隐藏，移动设备展开时保持占位、隐藏并禁用。正式组件与主视觉真源已接入；原型侧栏只演示布局，正式内容沿用官方Root和工具Tab。官方契约缺失或项目目录不可用时隐藏入口。真实宿主及视觉验收范围见开发日志。

文字规范由本文件维护；可执行视觉规则在 `docs/ui/ui-directions.html`，主题令牌在 `src/client/theme.ts`，宿主适配在 `src/client/styles.css`。`prototype.css` 和 `prototype-icons.ts` 是生成物，不手改。文档与代码不符时先核对选择器优先级、生成物及宿主覆盖，再同步修正，不能把旧描述当成新的设计决定。

设置分区标题下的介绍按用户指定保留。其他辅助文案精简重复操作说明，保留生效范围、保存方式、字段限制、禁用原因、备份恢复边界及结果截断；正常技能列表不显示内部启停机制，名称帮助仅非法输入时显示并关联错误。最近会话样式的统计依赖只在统计开启时显示一处；默认目录范围说明放在目录字段内部并关联读屏描述。普通主题卡不重复描述配色，经典湛蓝与跟随平台保留行为说明；规则编辑步骤沿用正文悬停提示，页面小字只说明保存方式。RSS地址示例移入占位；来源路径、计数、附件及关联文件作为数据保留。

不能仅按字号或`small`标签判断冗余：字段字数／上限、项目归属、来源归因、服务身份及工具说明属于数据；持续加载、异常、授权待完成与不可撤销边界按实际状态保留。连接器密钥仅在相关认证方式下说明留空保留／详情清除；导入重复处理、凭据去向及脱敏范围集中说明。文案清单只作当次源码审查快照，长期规则归入本节，执行结果与验证范围归入开发日志，不另维护并行清单。

技能来源与连接器市场来源卡片属于来源管理例外：整卡及名称文本不触发详情，也不使用整卡链接覆盖层、悬停阴影或指针光标；目录路径或市场URL替代通用说明，沿用12px辅助文字、单行省略及完整地址悬停提示。名称旁编辑图标复用36px图标按钮，悬停或键盘聚焦显示，触屏常显；原位编辑沿用40px普通输入，不新增字号、圆角或密度。Enter／失焦保存、Escape取消，同名及保存失败保留草稿。其余扩展卡片沿用既有详情交互。

添加技能、连接与订阅弹窗按用户指定采用左侧方式导航例外：「创建技能／上传技能」「添加连接／导入配置」「添加订阅／导入订阅」复用integration-detail-nav，各自只包含两项，不混入正文分区。沿用现有200px侧栏、850px下160px、650px下横排的响应式规则，按钮尺寸、焦点和选中态不变；已有技能／连接器／RSS详情及市场添加仍为单栏。

市场卡片操作统一36px文字按钮：技能未安装显示「安装」，保存后显示「已安装」并进入已有详情；连接器未登记显示「连接」，已有记录显示实时连接状态，只有握手成功显示「已连接」，其他状态保留连接中／需授权／连接失败等文案，点击进入已有配置。普通技能、连接器管理列表继续使用启停开关。安装回执按候选身份关联记录，已删除技能不视为安装；连接器已有配置按服务地址或stdio命令及参数匹配，不按名称判断。管理卡片标题、导出、RSS来源／原文和连接器帮助链接悬停不出现下划线，保留颜色及键盘焦点反馈，文章正文链接保留阅读排版。

推荐订阅的预填添加页只显示单栏内容，不出现「添加订阅／导入订阅」导航；普通添加保留两项方式导航。新增订阅保存后关闭添加页，进入「我的订阅」，选中新增来源、展开所属分组并定位导航，清空旧搜索、文章区回到顶部并仅刷新新增来源；文章列表与首页统计始终共用外观布局 → 统计卡片 → 时间范围，不设置局部时间下拉框，也不因新增订阅覆盖范围。刷新失败保留订阅与已有缓存并显示原因。编辑保存仍留详情，导入沿用原流程。

RSS分组名称编辑采用紧凑导航输入例外：36px高、14px／20px字体与行高、上下7px／左右8px内边距，宽度`min(100%,12ch)`，外层保留40px行高，超长名称在输入内横向滚动。理由是侧栏原位重命名需要保持导航密度，不使用普通表单的全列输入。Enter／失焦保存与Esc取消不变。分组名称悬停不显示下划线，只沿用行背景反馈。RSS更多菜单左边缘与三点触发按钮左边缘对齐，在按钮下方间隔5px展开；底部不足且上方足够时向上展开，右侧受窗口边缘约束。其余菜单定位保持既有规则。

### 0.2 字体、颜色与边界

| 角色 | 统一规格 |
| --- | --- |
| 正文、按钮、普通输入与选项 | 14px；单行控件行高20px，正文按所在阅读区域 |
| 辅助说明、时间、状态、待办优先级、附件数量及文件大小 | 12px；不得在窄屏继续缩小 |
| 分区标题 | 16px／24px，字重600 |
| 弹窗标题 | 20px／28px，字重600 |
| 可编辑待办标题 | 16px、字重500；与普通字段区分 |
| 正常／中等／强调字重 | 400／500／600；选中导航使用600 |

控件与列表使用 `--font-ui`，阅读主题仅指定页面／章节标题使用阅读字体。正文用 `--text`，辅助与占位文字用 `--muted`，控件底色用 `--surface`，控件边框用 `--control-line`，普通分隔线用 `--line`。悬停、选中、主按钮、危险及焦点分别复用 `--hover`、`--selected-bg`／`--selected-text`、`--primary-bg`／`--on-primary`、`--danger-text`／`--focus-tone`。不在组件里写独立配色，状态同时提供文字或图标。

跟随平台时，主按钮背景／文字／悬停分别继承宿主`button-primary-fill`、`label-primary-foreground`、`button-primary-hover`语义令牌；强调色`--accent`独立继承`state-business-primary`，不复用主按钮填充色。强调选中底色继承`state-business-tertiary`，文字继承`label-primary`；焦点、开关、控件边框、成功与危险状态使用对应公开令牌。开关轨道与滑块成对映射，通知强调色使用`--accent`。所有缺失令牌逐项回退当前明暗的经典湛蓝配色，警告颜色缺少已确认公开等价令牌时保留内置值。颜色直接引用CSS变量，平台换色自动更新；其余独立主题沿用既有配色，布局、字体及控件尺寸保持工作台规范。

正式插件启动时，首帧使用本机缓存的已确认主题，再以服务端设置为准；无有效缓存时保留中性骨架和顶栏占位，读取设置后才显示顶栏，避免默认蓝色闪现。设置预览不写缓存，明暗状态实时读取宿主。

待办列表的优先级、创建信息和附件数量保持同一行；优先级与附件数量不收缩，创建信息在窄宽度时省略并提供完整悬停提示，字号仍为12px。待办正文容器宽度300px及以下，附件计数只显示图标和数字，宽度充足时显示「N 个附件」；悬停提示和读屏名称始终保留完整数量说明。

### 0.3 输入框与选择控件

项目运行规则复用普通表单开关、40px名称输入与Picker。全局规则位于全局设置首项；全局停用时收起正文并保留草稿，重新启用显示原有内容；项目规则停用时仍可编辑正文。项目规则仅列表，支持名称／项目搜索与共享外层的详情页，应用项目采用12px标签、列表最多两行；删除在对应行悬停／聚焦时可见，触屏可见。多选Picker保持已有定位、宽度及焦点规则，点击切换并保持展开，点击外部／Escape关闭，无二次确认。

技能应用范围及连接器作用域多选将已选名称标签放在40px主题下拉内，复用rules-project-tag的12px辅助字号、7px圆角和主题边框，不增加控件高度或框下标签。标签单行排布，按内容区域实际宽度及标签尺寸保留能容纳的项，溢出用同款「+N」标签；单项超长省略，极窄时允许只显示数量。完整名称始终保留在title、选择框aria-label与多选菜单，数目只改变展示，不改变已选项目。面板宽度及字体变化后重算；组件移除后断开尺寸观察。

技能应用范围与连接器作用域共用同一个多选逻辑，各自在单个下拉中提供全局和项目，不另设应用项目字段：选择全局立即清空已选项目；全局已选时可直接选择项目并清除全局；项目允许多选。全局及有效项目始终可选，点击当前项可取消，空选、归档或不可用项目阻止保存及导入，保留草稿；菜单展开期间同步选中状态与键盘可选项。

两者共用`RulesEditor`：正文使用`--font-ui`的14px／24px、7px圆角、上下9px／左右12px内边距及普通输入颜色，最小高度176px。全局默认176px，项目详情默认`clamp(280px,48dvh,560px)`以适合独立阅读；两态共享边框与高度且允许纵向调整。焦点由外框沿用普通输入的边框及淡色2px光圈，内部文本域及规则搜索输入不重复绘制光圈。默认使用宿主Markdown渲染，点击／Enter编辑原文、失焦回预览，Escape只退出原文；未提供官方渲染器时安全显示纯文本，不执行原文HTML。输入法组合期间暂停保存，保留光标与原文滚动。规则650ms防抖、串行自动保存，合法规则不受其他无效草稿阻塞；失败保留输入且提供重试，其他配置仍点击保存。关闭设置先收尾规则请求，未保存时保持打开并提供明确放弃入口；取消不撤销已自动保存的规则。规则详情通过ModalFlow复用设置外层与焦点管理，设置内容隐藏保留，返回恢复列表位置及搜索。

私人订制位于项目配置之后，四个二级菜单复用`SettingsSubtabs`，正文复用`RulesEditor`的设置保存模式及默认176px高度，每文件20000字符；取消不提交档案。语音播报位于「其他组件」二级菜单，由「通用组件」开关控制显隐和启用；开关、服务选择、文本／密码／数字输入分别复用现有setting-row、Picker和field，不新增尺寸或密度。默认官方服务只展示音色Picker、Markdown过滤开关和密钥；选择OpenAI兼容服务才展示接口、模型、自由音色和语速，切换仅修改草稿，取消不提交。组件启用时，会话顶部提供单个喇叭图标，复用宿主`Button`的toolbar／sm规格，点击切换全局自动播报，关闭／启用图形与播放动画遵循第0.1节；提示显示启用／关闭或完整错误。回复底部通过官方`conversation.chat.assistant-actions`添加单个喇叭图标，按消息ID重播该条正文，播放中显示声波动画并可点击停止；组件启用且自动播报关闭时仍可手动重播。此行在工作台作用域外，样式作为宿主适配使用官方28px控件、17px图标及字体增量、6px内边距和官方圆角／颜色，跟随原行悬停及焦点显隐，不新增工具栏。缺少配置时保持可聚焦并在Tooltip解释原因；错误保留在Tooltip，不挤占头部宽度。

官方「插件 → 终端」中的工作台扩展位于宿主页面，复用官方SettingsForm、SettingsValueField、Input、Button与Menu，不套工作台主题作用域。顺序为字体／字号／配色／预览／默认Shell／命令限制，底部唯一保存。标题16px／24px、说明12px，颜色使用宿主令牌。名称说明在左、所有输入和选择器在右且统一320px，字号与命令字段使用官方字段组件；650px及以下上下排列、控件全宽。字体直接点击输入框展开／搜索，箭头只作装饰，无独立按钮；不支持字体枚举或权限拒绝时保留输入。所有终端菜单跟随实时锚点等宽；字体菜单沿用固定320px高，配色与Shell菜单按内容自适应、最高320px，超出后内部滚动，低高度窗口受宿主可用空间限制。配色使用独立菜单类，不借用字体固定高度样式。官方Menu的className只用于锚点根，listClassName才用于portal菜单，禁止混用导致输入宽度及菜单高度失效。工作台「其他组件 → 终端扩展」仅展示默认关闭开关，不重复字段。

规则预览共用一个正文滚动框，官方代码块的语言／复制标题栏随正文滚动，不吸顶遮挡后续内容；通过`.rules-md-preview .md-code-block>:has(>[data-code-block-banner])`限定标题外层的`position:static`和`z-index:auto`。仅覆盖规则预览，复制按钮及链接的点击／键盘操作不切换到原文编辑。

终端目录只使用官方条目，整页表单通过官方详情扩展挂载。宿主适配仅在`data-plugin-item-detail="shell"`内、扩展根节点实际存在时收起原`data-plugin-config`表单，不隐藏目录行、摘要或其他插件表单；扩展移除后自动恢复原表单。样式依赖`:has`并在接入前探测，缺失能力时保留原页面；不通过第二个同名目录注册实现页面覆盖。

字体输入下拉箭头复用官方`IconChevronDownOutlineRegular`（12px），在16px容器内垂直居中，右侧12px；不使用受字体基线影响的文本箭头字符。

终端字段不展示「已自定义」状态标签，自定义状态下只保留官方「恢复默认」操作；字号及命令执行限制共用此规则，字段校验与重置行为不变。

终端配色下载文字操作与官方「恢复默认」共用文字状态：默认使用宿主次级文字色，支持悬停时变为主文字色，无下划线、背景或尺寸变化。

字体首次枚举、失败与搜索空结果的提示放在固定高度菜单内部，不在输入框下临时新增表单行；字体菜单预留滚动条空间，异步列表载入不改变表单高度或菜单内容宽度。

终端独立配色位于字号后、预览前，复用同一320px控制列与官方Menu，预览仍紧随字体／配色设置。提供跟随平台、自定义和Catppuccin四种风格；下载按钮只生成草稿，不作为第二个保存入口。自定义展示背景／文字／光标／选区，16色ANSI字段折叠收纳，文字输入沿用官方Input并校验六位hex。预览展示文本与16色色样，这是颜色选择所需的局部配色例外，不将终端色板应用到设置页面或工作台主题。保存后更新终端显示层；关闭终端开关或选择跟随平台时恢复官方显示，保留已保存色板。

默认Shell保存后核对浏览器实际持久化结果；失败说明放在Shell控制列下，复用既有错误文字样式与统一保存失败反馈，保留选择草稿，不新增确认按钮。诊断标题中的用户会话名称与固定异常标签分开渲染，翻译只处理标签；恢复阻断原因逐项翻译，路径与其他用户数据保持原文。

普通文本输入支持直接编辑、粘贴与光标选择。目录输入点击文字区域只编辑；右侧文件夹按钮或 Alt + ↓ 打开宿主选择器，取消保留原值。选择型下拉点击即展开，不要求先输入内容或再点确认；确有搜索能力时输入用于筛选。标签与输入建立关联，placeholder只作示例，不能代替标签。

「项目配置」复用共享二级页签，顺序为「全局设置／初始化设置／项目规则」。全局页放默认根目录、Agent 待办权限及全局规则；初始化页提供「项目基础文件／Agent 协作规范／Git 初始化」三个独立开关，初始全部关闭。每组用共用 `setting-row` 说明实际生成文件；Agent 开启时显示「生成提交规则」子开关，默认开启，其下复用全局规则的Markdown编辑器，默认176px，点击／Enter编辑原文、失焦返回预览，最多10000字符。不提供折叠、重复字段标题或恢复默认按钮，保留「提交规则内容」读屏名称；提示通过「保存设置」保存，预览和原文均关联校验错误。提交规则作为初始化模板留在本页，仅作用于后续新建或补齐，不追溯已有项目。生成条件成立时纯空白内容阻止全部设置保存并显示字段错误及页脚提示；关闭子项或分组时收起编辑区并保留草稿。Git 组后提供共用开关「添加已有项目时补齐缺失内容」，默认关闭，行内说明保留已有文件与 Git、所有组关闭时不补齐；不再显示其下关于执行时机和已有 AGENTS 的额外小字。所有修改跨分类和二级页签保留，统一保存；取消及失败不修改已存配置。添加项目弹窗仅保留已有目录、项目名称与创建位置，不展示初始化选项或文件清单；新建和开启补齐的添加操作由服务端读取最新已存配置，成功添加提示补齐／保留项数。两种模式保持现有网格占位，模式标签按可用宽度换行，不缩小字体；提交期间锁定控件，失败保留名称与路径并可重试。

快捷输入的语音按钮复用官方 `conversation.input.activity` 组件，置于模型和发送之间；只在官方语音组件已挂载时显示。请求麦克风、录音、转写与反馈展开时隐藏添加／项目／模式及模型控件但保留挂载，活动区域使用工具栏剩余宽度，文本区与发送按钮仍可见，发送暂时禁用；收起后恢复原布局。按钮、波形、取消、停止、重试及准备提示沿用官方规格，不复制组件样式。textarea选区转换为宿主原子节点坐标，引用内部光标按官方投影规则移至该引用之后；版本冲突或超出20000字符时保留转写结果，用户调整后再插入。

同排控件按外框对齐，不通过单侧额外margin补偿。弹性字段使用 `min-width:0`，图标和固定操作不收缩；长值省略并提供全文提示，编辑区允许查看完整值。输入组内按钮使用明确的直属选择器，尺寸不能传播到浮层选项。

### 0.5 状态、菜单与键盘

技能应用范围与连接器作用域多选复用普通表单40px主题下拉与共用选项菜单，点击输入区域直接展开，不增加确认按钮；选中标记、主题、悬停和键盘规则与单选共用。多选点击后保持展开并更新已选数量及项目标签，支持Enter／空格选择、方向键及Home／End移动、Esc收起并返回触发器，单选仍选择后收起。已选标签复用项目规则标签，不新增尺寸或颜色。

全局搜索的「全部／会话」分类在官方「历史会话搜索」实验套件启用且就绪时搜索标题和正文，不显示依赖提示。停用时只搜索标题；仅确认套件可用且未默认隐藏时，在列表下方复用`wb-help`提示添加启用，当前默认隐藏不提示。输入提示和页脚随实际搜索范围变化，待办内容统一称为「描述」，搜索提示与命中标签不再称「备注」。项目／待办分类不显示正文依赖、检索状态或报错。

普通输入与普通表单下拉聚焦统一中性 `--focus-tone` 边框及同色12%透明度的2px外圈；复合输入只在外框绘制，内层不得叠加边框、外圈或下划线。按钮保持可见键盘焦点，菜单使用内嵌焦点边界；紧凑项目导航、分支和宿主控件保留各自焦点规格。

项目列表、详情会话／待办的悬停及内部键盘聚焦使用`--entity-hover-bg`，直接引用官方侧栏及菜单的`--dsw-alias-interactive-bg-hover`；离线原型或宿主未提供令牌时，浅色回退`#2631480f`、深色回退`#ffffff14`。项目宫格外层始终使用官方`--dsw-alias-bg-base`（缺失时回退surface），不叠加悬停底色；采用飞书Base首页宫格的整卡上浮方式：细指针悬停或内部键盘焦点时`translateY(-4px)`，transform与阴影均300ms ease，离开平滑归位，不循环弹跳、不缩放、不改变布局占位。浅色阴影为`0 4px 16px 4px rgba(31,35,41,.03),0 4px 8px rgba(31,35,41,.02),0 2px 4px -4px rgba(31,35,41,.02)`；深色仅将阴影换为黑色20%／14%／12%，保证深底可辨。减少动态效果时取消位移与过渡，触屏不启用悬停上浮。内部统计小卡片及文件夹图标底块保持既有4%正文色混合surface的底色，悬停与内部聚焦均不变色，以整卡动效统一表达交互目标。项目列表仍在surface上叠色，会话／待办透明行叠在所在面板上。宿主主题变化自动生效，插件主题的文字及详情基础底色仍保留。悬停不额外加深边框、不使用主题选中底色。整体详情卡片仍为连续列表，不增加独立白底或内描边，既有轻分隔线保留；列表、按钮、菜单和危险操作不套项目宫格上浮动效。

首页统计卡按实际可见数量均分行宽，隐藏卡片不保留占位；以统计区域容器宽度响应，四卡在720px及以上保持四列，420–719px两列，419px及以下单列，1–3张按数量与现有两列断点适配。统计卡复用项目宫格的上浮距离、过渡、主题阴影和减少动态效果适配，保留原surface底色、line边框及文字，悬停、按下和键盘焦点均不变色；右下进入箭头仍按原规则出现。统计卡作为可点击明细入口，是上述「普通按钮不套宫格动效」的明确例外；内部数据、状态图标和明细打开行为保持既有实现。

技能、连接器、RSS扩展原型沿用上述统计卡规格，设置提供七项选择但最多开启六项；开启第七项时撤销本次勾选并就地提示「最多显示 6 张统计卡，请先关闭一项」，保留原六项。三种管理面板复用统计抽屉与二级页签，上传／导入归添加弹窗的两项左侧方式菜单，单项导出归详情状态行；RSS批量导出归我的订阅标题区，均不保留独立导入导出菜单。有分组的页面沿用运行中／会话的两栏规格：左侧210px、900px以下180px，搜索固定在分组上方，分组列表独立滚动，分组与卡片区之间无竖线。窄面板搜索与分组选择器依次置于内容顶部，搜索只保留一个；无分组页省去左栏及窄屏选择器，搜索保留在内容工具栏。管理搜索复用36px统计搜索，普通表单使用40px输入／下拉，操作使用36px按钮。

三类管理内容统一使用主题surface、line与10px圆角的卡片网格，来源卡片遵循第0.1节例外。默认两列，无分组宽面板三列，650px以下单列；快捷操作独立响应。已有详情／编辑均单栏，普通添加按第0.1节两项左栏，市场及推荐添加单栏。顶部返回、条目名称和关闭按钮，正文独立滚动、底部操作固定。技能查看页只留编辑，只读来源禁用编辑；连接器／RSS底部编辑与移除，状态行承担单项导出。底层管理弹窗暂不可交互且保留菜单、分组、搜索和滚动，返回恢复状态与焦点。表单／按钮沿用40px／36px规格。编辑取消回详情并保留草稿；技能保存返回列表，RSS新增定位文章列表、编辑保存留详情，连接器保存留详情或继续授权。关闭不丢弃草稿，OAuth及文章阅读在详情内切换。正式组件及视觉真源共用这些规则。

### 0.6 响应式、复用与验收

宽度断点使用工作台容器宽度；`pointer`、`hover`与减少动态效果仍属于能力查询。窄屏先调整列数、宽度、换行和辅助文案，不另写一套小字号。同排固定操作保留占位，360px面板不得横向溢出；减少动态效果时取消非必要过渡。

650px以下的英文设置一级导航每列至少160px（受可用宽度约束），按实际空间调整列数；360px为两列，保留单行名称与共用字号，避免长菜单文字相互覆盖。

开发提交前逐项核对：

1. 控件用途和复用入口来自本节，同类尺寸不另写局部变体。
2. 修改共用规格时同步真源与全部使用处，检查动态类名、选择器优先级、组合按钮与嵌套菜单。
3. 核对全部主题的明暗外观，以及360px、650px边界和常规宽度；检查正常、焦点、禁用、长值、空值、失败及处理中。
4. 验证键盘、输入法、取消、草稿保留和错误重试；状态样式不能改变写入或上传限制。
5. 代码改动运行typecheck、测试和构建；生成逻辑改动另核对CSS不变量及构建幂等性。浏览器验收测量外框尺寸和computed style，真实宿主验收独立记录，不用单元测试代替视觉结论。

### 0.7 现有差异与适用边界

普通输入及普通表单下拉统一使用 `--control-radius:7px`，共用规则覆盖历史温暖主题的通用按钮圆角；复合待办输入为10px、统计搜索为8px，内层输入不套普通控件圆角。项目导航、分支、开关、文件上传及宿主会话输入保留独立规格；新增同类控件不得自行更换。今后调整输入尺寸或圆角，应作为一次共用样式改动同步全部同类控件，并更新本节。具体已验证范围只记在开发日志，代码完成不代表已安装或已在真实宿主验收。

宿主分支条沿用官方28px控件与13px文字，分支列表及说明12px；插件更新的新旧版本代码沿用官方13px等宽字，状态、说明与失败提示12px。此类宿主规格仅用于对应适配区域，不传播到普通表单、列表操作或保存提示。

## 2. 首页

### 快捷输入与最近会话

正式快捷输入保留原型中的圆角输入卡和 textarea；复用 Harness 官方添加菜单、项目菜单、模型控件及输入服务，不嵌入 `conversation.content` 工厂。添加菜单沿用宿主主题，通过独立浮层按面板可用空间向下或向上展开，避免顶部输入卡压缩菜单高度；输入卡与项目、模式触发按钮仍使用工作台主题令牌。项目菜单沿用官方文件夹图标，仅显示项目名，提示也不显示路径；归档与不可用项目禁用。模式弹窗展示官方预设名称、说明和可用项，自定义预设保留自身文案。模型控件与添加菜单共享 SessionProvider，沿用官方提供商、模型和推理强度菜单，选择提交期间禁用发送；不在发送时重新选择模型。模型区最大宽240px，面板不超过600px时收至120px，不超过420px时使用官方紧凑图标。

输入宽度以 1120px 为计算基准，常规为其 6/7，最大 960px、最小 640px；空间不足时下限收至可用区域减 32px。始终居中且无横向溢出。

快捷输入项目与模型弹窗固定从按钮下方8px展开，最多360px高；以工作台和可见视口交集中的下方空间为限，底部保留8px，不自动向上翻转。项目沿用官方列表滚动层，模型列表保留顶部搜索框与分组内部滚动；模型根菜单、模型列表和推理强度页切换后重新定位，滚动与窗口大小变化时同步。仅调整当前快捷输入关联的浮层，不影响宿主会话页菜单。

文件拖入作用于整张输入卡，使用主题强调色内描边，空输入提示「松开以添加文件或图片」；离开、放下、切换项目／模式或进入提交状态后恢复。支持剪贴板图片，与文字同时粘贴时在选区插入文字并保留剩余正文。拖入、粘贴及菜单选文件共享官方导入入口：桌面普通文件／目录生成路径引用，图片上传，附件按钮显示上传状态，失败时提供「重试上传」。拒绝提示不清空草稿，普通文字拖入／粘贴不被文件事件拦截。

工具行左侧依次是添加、项目、模式，右侧是模型、发送；下方分支条跟随官方 `dsh-experimental-forge-bundle` 启停，启用并挂载 forgePanel 时显示、禁用时整体隐藏。原型显示分支条时代表 Forge 已启用。原有容器响应式、输入圆角和宽度不变。添加弹窗锚定输入卡，附件和引用交给官方输入服务处理；旧首消息失败重试保留原有幂等链路。

最近会话使用按钮形态且输入框可见时，按钮居中贴近输入框下方，外边距统一由 `--home-shortcuts-gap:12px` 定义；输入卡的下边距归零，避免叠加间隔。卡片形态与隐藏输入框时的排布保持各自区块间距。详情页会话列表及会话空状态共用首页的圆形气泡图标，尺寸与颜色保留详情页规范。

设置中的最近会话样式选项仅显示「卡片」与「按钮」，不在选项名中显示数量。添加项目弹窗使用「添加已有项目」标签，提交按钮为「添加项目」；字段为「项目路径」，输入框提示「输入或粘贴项目路径」，下方提示「也可点击右侧图标选择项目。」。输入框可直接编辑和粘贴，文字光标，不因点击打开选择器；右侧图标与 Alt + ↓ 提供项目目录选择。

最近会话无区域标题：卡片最多 5 张，最小高 60px、12px 圆角，左侧 28px 轻色底块内放 16px 圆形气泡，右侧 14px／500 字重标题与 12px 项目名，居中限宽 1120px；进入箭头保留占位，悬停或键盘聚焦时显示，触屏常显。按钮高 32px、10px 圆角、主题细边框，使用 14px 同款圆形气泡，固定单行、长标题省略并提供全文提示；根据可用宽度、各按钮实测宽度与 8px 间距显示完整连续前缀，宽屏可超过 3 个。按钮区域与输入卡共用外宽规则，左右内边距为 `clamp(24px,5%,48px)`，居中排列，隐藏的候选不可聚焦。卡片按面板宽度变为 5／3／2／1 列，条目数据不截断。没有会话时隐藏整个可选区域，不显示占位提示。悬停、按下和焦点共用主题令牌。

### 统计与项目

七项统计卡提供运行中、所选时间范围内的会话（默认7天）、未完成待办、诊断、技能、连接器与RSS明细，默认显隐、顺序、数字口径与无小字布局遵守第0节。12px圆角，标签与26px数值左对齐；右上角图标为24px框内18px图形，无彩色色块；会话统计使用圆形气泡。诊断主值为目录／缓存／孤儿／空会话四类异常记录总数，与其他卡片共用字号、字重及正文颜色；检查说明及非零类别数保留在悬停与无障碍描述。仅状态图标使用主题成功／危险／中性色，不将读取中的状态显示为成功。诊断页「重新检查」按钮位于标题同一行右侧，复用「添加技能」的36px主按钮，图标、字号、圆角、间距及状态均遵守第0节；说明及横线保留在下方，仅在有缓存或孤儿修复候选时显示紧凑操作栏，空会话批量操作放在右侧操作区，不重复显示分类标题。每条记录的修复操作独立成按钮，不嵌套按钮。窄面板检查状态改为上下排列，共用主题边框、面板、文字及危险色。箭头在右下角保留位置，仅悬停或键盘聚焦显示；减少动态效果偏好下取消过渡。窄面板统计切换为两列。

预览工具栏提供「六卡预览」，一次显示运行中、待办、诊断及三项扩展，仍可在设置中替换。

扩展统计区域最大1440px，独立命名容器 `workbase-stats` 按区域宽度响应：五卡在900px及以上五列、720–899px三列；六卡在960px及以上六列、720–959px三列；四卡在720px及以上保持四列；所有多卡在420–719px最多两列、419px及以下单列，实际列数不超过开启卡片数。卡片间距12px，未满的末行不拉伸成整行；统计抽屉与设置抽屉同宽（左右各留50px、最宽1580px），输入卡与最近会话保留原宽度基准。

技能二级菜单仅为「全局技能／项目技能／技能来源／技能市场」，标题按钮固定「添加技能」。全局技能按来源分组，项目技能按项目分组；技能来源只展示目录、启用开关与「添加路径」，不展示具体技能，不加分组。技能市场不分组；不提供回收站及删除／恢复入口，历史回收数据保留兼容。

连接器二级菜单为「我的连接／连接器市场」，标题按钮固定「添加连接」。我的连接按全局及项目分组，移除重复的范围选择器；启用在前、组内按安装时间降序。连接器市场不分组，搜索置于内容区上方，右侧「市场来源」及刷新按第0.1节技能市场共用规则。来源详情布局与操作按第0.1节执行。

连接器编辑、市场配置、工具、来源和OAuth弹窗共用技能的单栏详情。添加连接的「添加连接／导入配置」使用第0.1节规定的左侧方式导航，保留独立草稿；HTTP／stdio、认证及扩展默认字段沿用40px表单，成对排布、窄面板单列。导入复用技能文件选择区域，支持.json文件及可编辑JSON，读取或输入后自动生成候选；范围变化重新预览，底部只有导入所选。连接详情去掉重复名称块，标题下复用todo-detail-summary／meta显示状态、范围、协议与认证；导出配置及异常重连／授权使用技能导出的12px文字操作。底部保留编辑配置与原移除入口，启停在列表开关操作；工具折叠、搜索、逐项参数和开关保持原交互。市场点击卡片或添加直接进入预填配置表单，保存后留详情或继续OAuth。创建、编辑、市场配置和导入共用第0.3节作用域多选，一条连接保存scope与projectIds，项目分组按包含关系展示，全部连接不重复计数；旧单项目记录兼容读取，身份与安装时间保持。

RSS二级菜单为「我的订阅／推荐订阅」，标题按钮始终「添加订阅」，我的订阅标题区提供批量「导出订阅」。分组栏保留36px添加／编辑图标及窄面板选择器，移除分组保留订阅到默认分组。来源按持久手动顺序展示，新增追加；启停沿用列表开关。普通添加采用第0.1节两项左栏，推荐预填表单单栏；新增保存定位我的订阅并单源刷新，编辑保存留详情。导入复用连接器文件选择与自动候选预览，支持.opml／.xml及可编辑内容，默认分组变化重新预览，底部只有导入所选。订阅详情、编辑、分组、导出和文章均单栏；状态、分组、检查时间位于标题下，刷新及单源导出沿用12px文字操作，底部保留编辑与移除。文章来源／时间移到标题下，阅读返回保持原状态。批量OPML包含全部订阅与自定义分组，单源导出仅包含当前订阅。

新增与编辑、启停、移除确认、导入候选预览、配置／OPML导出、OAuth等待／取消／完成和文章阅读在原型内可操作，数据单独保存到浏览器；目录扫描、外部连接、真实授权、定时刷新及订阅网络请求均未接入。

项目工具栏统一放标题、互斥活跃／归档／收藏、字段设置及宫格／列表切换，不显示右侧活动或排序说明。默认宫格，项目总览占满下方宽度。

项目宫格头部为文件夹图标和两行信息：第一行名称与可选状态，第二行目录和有效最近活动相邻，以中性细线分隔；更多留右侧。中间统计按开启字段自适应，底部仅在有最近会话时显示。没有活动时间时隐藏活动及分隔符；有效零值统计保留。隐藏字段不留空区域，长内容省略并保留全文。

项目宫格、列表及详情名称前的文件夹使用官方工作区展开态 `IconFolderOpenRegular` 的图形，保留原有图标框尺寸与主题颜色；运行中、目录异常仍使用相应状态图标。文件夹图形在原型中统一定义，目录选择等共用入口同步使用。

宫格和列表的目录辅助行使用 2×2 实心四圆点，单点直径 2.4px，中心位于 14×14 图标框的 (4,4)、(10,4)、(4,10)、(10,10)。图标框和目录文字均为 14px、图文间距 2px，在 18px 行高内垂直居中，颜色继承辅助文字，不显示 `/` 前缀。图标不收缩，目录名称独立收缩省略，点击仍复制完整路径。

列表表头与行共用列模板，项目名和目录为主要信息，辅助列顺序为近期活跃、待办、归档、最近会话、最近活动、状态，更多固定末列。隐藏字段删除整列，桌面字段过多只允许列表区域横向滚动，窄屏辅助字段按标签和值换行。

正常项目不常驻「目录可用」文字。状态字段关闭后以图标和完整无障碍描述保留状态；收藏中的归档内容仍显示只读标识。

## 3. 项目详情

### 头部与分栏

第一行「主页 › 项目图标 项目名称」，主页及项目名 15px，项目图标 22px，右侧更多。名称点击重命名，悬停／聚焦显示淡色铅笔；归档名称只读，详情不显示置顶。

第二行左侧「四圆点 目录名称 ▾ | 最近活动 · 时间」，与首页相同的 14px 实心四圆点图标、14px 目录文字和 12px 箭头放在同一目录选择按钮内，18px 行高，图文间距 2px、箭头间距 6px，垂直居中，不显示 `/` 前缀；不在按钮外另放文件夹。项目名称前仍使用官方文件夹图标。两行间距 4px，统一左边界。目录点击切换，图标不收缩，名称独立收缩省略，完整路径通过提示和菜单展示；复制完整路径在更多菜单。

第二行右侧为唯一列表／整体卡片切换，同时控制会话与待办。左侧允许收缩省略，切换控件不被挤出，不增加工具行。

默认会话 65%、待办 35%，保存范围为会话 40–70%。24px 分隔交互区支持拖动及方向键每次 2 个百分点，Home 恢复 65:35，End 到 70:30。已有比例保留，取消与保存失败恢复旧值。

双栏最低内容宽度为会话 280px、待办 240px；850px 及以下切「会话／待办」页签。页签保留 DOM、草稿、选中和滚动，未选面板不进入键盘序列；搜索待办自动切对应页签。

常规桌面详情填满可用视口，头部、两栏标题及工具行固定，仅列表独立滚动。按实际视口和软键盘计算余高；余高不足 260px 时允许主内容滚动并保留 360px 列表区域，避免操作被裁切。

### 列表与整体卡片

列表模式两栏开放排布；卡片模式分别将标题、工具行和列表包在整体卡片中。两栏共用 panel 底色、细边框、10px 圆角、12px 内边距，无阴影，拉伸至相同高度。条目仍为普通列表行。

两栏标题行及工具基线对齐，取消单侧顶部补偿和中间重复装饰竖线。拖动柄仅悬停、聚焦或拖动时显示，原交互区保留。

会话标题和待办标题均为单行省略。会话隐藏摘要，保留时间及状态；待办保留来源及时间，辅助文字使用第0节的12px，不通过降低透明度使文字难读。全文由提示、编辑或详情入口查看。

会话置顶紧跟标题，6px 间距并垂直居中；标题按内容收缩，置顶占位稳定。项目／会话置顶仅悬停或键盘聚焦显示，已置顶也遵循该规则；触控稳定可达。收藏只在更多菜单，不显示常驻星标或重复置顶菜单。

会话与待办悬停及键盘聚焦背景统一使用主题 hover。任务行约 56px 最小高、8px 上下内边距、5px 圆角；当前精确尺寸和图标以原型 CSS 为准。辅助信息遵循第0节的12px规格。

### 待办分组

待办标题输入保留 Enter 快速创建，旁边提供「完整新建」。行首完成、中间标题打开详情、行尾删除；辅助行依次显示可选优先级、来源时间、附件数量，不在列表或卡片展示备注正文，备注仍可搜索。待处理按高／中／低／未设置排序，同级按更新时间倒序；添加与搜索共用同一输入框，右侧完整新建与优先级筛选原位切换，操作占位稳定。删除按钮仅当前行悬停或键盘聚焦时显示，保留占位避免文字跳动；触屏常显，点击直接删除并提供 5 秒撤销。待处理使用轻量 16px 圆圈，悬停／聚焦可用完成按钮时出现淡勾号，已完成用圆圈内勾；分组展开箭头和完成图形明确区分。

完整新建和详情共用唯一居中弹窗，尺寸、标题栏、底栏和控件密度见第0节，仅内容区滚动。状态只读，项目和创建信息紧接header下方，标题与优先级在其后同排；描述与附件集中在同一内容区域，不分菜单。优先级复用主题下拉，显示色点和选中勾；描述只用一个编辑／预览切换，底层沿用`note`字段。关闭只在右上角，底栏左侧保存状态、右侧模式与发起会话组合按钮和保存按钮；400px以下隐藏保存状态避免溢出。不提供评论、变更记录或截止日期。

附件不限制格式；图片缩略图失败回退文件图标，其他文件显示名称、大小与下载。最多10个、单个10MiB，支持选择、拖入、粘贴、移除及失败续传。未上传附件禁止发起会话，草稿不会自动发送。全部样式使用工作台 surface、panel、text、muted、line、accent、danger、success 等令牌，适配柔和紫晶、清新森林、暖纸阅读、经典湛蓝和跟随平台的明暗外观。布局规则修改真源，宿主覆盖仅处理通用弹窗样式优先级。

「待处理」「已完成」始终可见，显示数量；默认待处理展开，已完成入口在底部。点击任何分组只展开该组，点击已展开组则切另一组，空组仍保留入口和空态。网格高度与箭头约 200ms 过渡，减少动态效果时立即切换。

两组分别独立滚动、按项目记忆，收起面板 inert 且不参与焦点。完成／重新打开不自动切组，保留连续操作焦点；搜索或统计定位先展开目标组，再滚动、高亮和聚焦。状态变更撤销入口不因普通提示丢失。

## 5. 抽屉、菜单与搜索

弹窗底栏按钮、标题栏及输入控件统一遵守第0节，主次与危险颜色仍使用各自主题令牌。

统计待办页标题右侧提供「添加待办」，与「添加技能」「重新检查」共用36px主按钮规格。点击复用待办编辑器打开创建弹窗，默认当前分组项目（全部项目时用当前活跃项目或首个活跃项目），可通过共用选择器改选其他活跃项目。无活跃项目或读取中禁用创建入口；关闭恢复原统计列表，保存后刷新列表及首页待办数，保留分组、搜索、滚动和添加入口焦点。创建与现有待办详情分别处理返回，避免把新增任务误判为原待办消失。

设置及统计使用第0节定义的底部抽屉；只保留顶部16px圆角，约300ms上滑，减少动态效果时取消动画。设置标题和底栏固定，中间独立滚动；统计概览不设横向footer，内容区延伸至底部，左侧分类与底部操作分区，关闭入口位于侧栏底部并用主题横线分隔，同时保留右上角关闭按钮。窄屏使用顶部分类，侧栏底部关闭入口隐藏，由右上角关闭；考虑安全区域。统计中的详情／编辑弹窗继续保留保存等必要操作栏。两类弹窗共用尺寸变量。

运行中、会话与待办页内采用项目分组导航：左列210px，900px以下180px，含项目搜索、全部项目、项目名及记录数量，路径只保留悬停提示；右侧直接显示可打开的记录，无重复标题、路径和总数。两列间去除竖线，分类标题为普通16px文字，说明下方留16px内边距并显示1px主题边界横线，无主色短线或二级菜单。搜索框及外层聚焦遵守第0节，弹窗通用表单标签的纵向样式不作用于此搜索框。宽面板分组列表与记录独立滚动，650px以下上下排列，项目列表最高180px、内容随抽屉正文滚动。搜索支持项目名和路径，同名项目按身份区分；文字、选中和悬停遵守共用规范。

诊断复用上述布局，导航固定为「全部异常／目录异常／列表缓存／孤儿子代理／空会话」，显示异常数量，零异常类别仍可选择；项目不再作为诊断分组维度。顶部「重新检查」与技能页「添加技能」复用同一36px主按钮规格，14px文字、8px圆角、7px／12px内边距，颜色、图标、间距、悬停及禁用状态沿用共用主按钮，不另设诊断按钮变体。右侧内容区不重复显示分类标题、数量及标题下分隔线，直接呈现结果或空状态；类别与数量已在左侧导航表达，内容区保留随筛选更新的辅助技术标签。搜索异常内容、项目、路径与会话标识，右侧记录保留归属与路径，空类别据实际检查状态显示正常、能力不可用或未完成。空会话批量删除作为右侧操作，不附加重复分类标题；范围不受搜索条件影响，执行前确认范围，跳过正在使用或状态变化的记录。

插件批量更新使用官方Modal、Button和StateDot，仅展示用户profile安装的非官方插件。确认阶段逐项显示13px等宽新旧版本对照，旧版本用辅助色；版本区使用官方模块背景、圆角与箭头，下方显示安装源及更新期间短暂停止、失败时保留或重装旧版本的说明。列表独立滚动，头部和确认按钮固定，进度与结果保留来源、恢复、失败输出及需重启提示。

设置七分类顺序及扩展快捷入口遵循第0.1节；复用共享设置、调色盘、开口文件夹、归档盒与组件图标。外观布局合并原外观配置与首页显示，复用共享二级页签呈现「首页模块／统计卡片／主题配色」，默认首页模块；数据统计关闭时隐藏统计卡片页签，保留卡片与时间范围配置，不新增第三层导航。Header打开设置默认进入通用配置。备份恢复置底，包含「数据备份／数据恢复／执行状态」，复用现有二级页签样式与键盘导航；默认数据备份，执行状态分区展示备份与恢复结果，切换时保留操作表单和任务订阅。项目配置包含全局设置、初始化设置与项目规则，控件分工见第0节。其他组件默认显示通用组件，语音组件开启时增加语音播报页签。明暗提示放在主题配色页签内、主题卡上方，颜色跟随主题；主题卡桌面两列、窄屏单列，五个选项自然换行。主题即时预览，保存保留、取消恢复，跨分类与页签草稿保留，统一保存。统计卡继续进入统一工作台概览。

字号按角色统一：设置项、表单标签和一二级菜单 14px（未选中500、选中600），辅助说明、时间、状态12px，分区标题16px，弹窗标题20px；窄面板不缩小字号。侧栏名称和位置控件右对齐等宽，480px以下上下排列。统计卡片页签不加从属缩进竖线；最近会话样式与侧栏设置保留从属层级。窄面板一级导航按可用宽度自动分列。

通用设置首项为「启动桌面端时打开工作台」，使用与其他设置一致的主题开关，说明保存后下次启动生效；默认关闭。设置保存与取消沿用统一事务，不即时切换主页面。

默认项目根目录与已有项目目录使用 `DirectoryInput`，点击输入框只编辑或粘贴路径；文件夹按钮或 Alt + ↓ 打开宿主本地目录选择器。取消选择保留原值，失败在字段下提示；选择中禁用提交。HTML 原型展示明确标注的模拟目录列表。

菜单继承主题底色、边界和状态，受实际视口限制，低高度内部滚动。普通项目选项显示名称与完整路径，重名可辨；快捷输入项目菜单仅显示名称并沿用官方菜单键盘交互。工作台自有菜单的宽度、打开焦点、键盘、禁用和尺寸变化行为遵循第0节。

更多菜单与字段菜单使用整行悬停背景 `--hover`，键盘焦点使用 `--focus-tone` 的内嵌边框；常用操作与项目管理分组，危险操作独立分组并使用 `--danger-text` 与面板混合出的淡色底纹。字段开启由主题色复选框表达，关闭不弱化整行文字，点击后保持展开；16px 复选框固定右侧，名称独立收缩。尺寸、行高与字号见第0节，受工作台面板边界限制。标题与视图工具栏的图标尺寸只应用于直属按钮，避免嵌套菜单项缩成图标宽度。

详情页项目选择器属于带说明的菜单，宽度遵守第0节：上方14px半粗项目名，下方12px等宽完整路径；两行各自禁止换行、超长省略，悬停提示完整路径。选中使用 `--selected-bg` 与 `--selected-text`，触发按钮仍为四圆点与目录名。

会话预览与待办详情共用第0节定义的居中弹窗。header直接显示会话名称，单行省略，悬停展示全文，不显示「会话预览」标签；状态附带图标，与项目、更新时间合并在header下方摘要区。标题区、摘要与底部操作固定；正文占据剩余空间并独立滚动，短内容也保留统一外框尺寸。无正文、读取中、失败提供明确说明，失败可重新读取；底部提供关闭与打开会话。所有颜色来自主题令牌，适配柔和紫晶、清新森林、暖纸阅读、经典湛蓝、跟随平台的明暗外观。

搜索悬停／聚焦／有关键词时加长，空关键词时展示搜索范围提示，输入框和浮层等宽、同左边缘，下方间隔8px。结果按下方剩余高度限制并独立滚动；离开搜索区域关闭结果、保留关键词。自有选择菜单的尺寸变化行为见第0节。

结果按项目／会话／待办分组，显示归属、真实摘录及归档／完成状态。宿主不提供命中数或消息定位时按当前限制说明，不用示例结果伪造真实能力。`⌘K / Ctrl+K` 聚焦、方向键选择、Enter 打开、Esc 保留词关闭。

弹窗及遮罩仅覆盖插件工作台显示区域，不覆盖或锁定宿主侧栏。设置抽屉按工作台高度计算，顶部预留 50px、底部贴齐；菜单和选择器定位限制在当前弹窗、工作台与视口交集内，内留 8px，靠底向上展开。打开弹窗只锁定工作台背景，Tab 在弹窗内循环，关闭恢复入口；下拉菜单的 Escape 先关闭下拉。列表重绘按实体或动作恢复焦点。长文本详情可选择复制，剪贴板失败仍能查看完整路径。

自有选择器和操作菜单宽度遵守第0节；快捷输入的官方项目与模型菜单沿用宿主规格。HTML原型模型列表仅为示例，推理强度以正式宿主控件为准。侧栏位置统一列「顺序第1／2／3个」及「倒序第1／2／3个」；名称与位置控件等宽右对齐，选项不增加控件宽度。

## 6. 异常、写入与验收

Toast 位于工作台顶部中央（距面板顶部68px），最大宽度520px，左右至少16px；文字使用第0节的14px正文规格、20px行高、10px圆角。背景为96% `--surface` 与4% `--primary-bg`混合，文字用`--text`，边框用`--line`；成功图标用`--success`、信息图标用主题主色。关闭用28px图标按钮，悬停与焦点使用主题令牌；较长文案可换行。层级高于工作台模态遮罩，弹窗开启时提示不设为inert；成功显示3.5秒，信息根据字数显示5–10秒，相同文案再次触发重计时。提示用礼貌状态播报，不自动夺焦点。

空、加载、错误在对应区域展示，失败保留成功数据；顶部同步失败提示数据可能过期并提供刷新。目录异常持续说明原因，待办和历史记录不丢失；归档内容业务只读，个人收藏／置顶不解除限制。

创建、编辑、归档、移除、删除、设置及布局只在保存成功后反馈成功或关闭；失败保留输入和原状态。项目迁移已接预览和记录抽屉，执行与撤销仍缺安全宿主事务接口。
