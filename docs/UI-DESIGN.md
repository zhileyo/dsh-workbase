# DSH Workbase · UI 设计规范

更新日期：2026-11-12。共用规则集中在第 0 节；后续章节只补充具体场景。需求统一见 [PRD](PRD.md)，所有HTML演示集中在 [ui-directions.html](ui/ui-directions.html)，实际实现与验收边界见 [开发日志](../.agents/notes/dev-log.md)。

## 0. 共用一致性规则

### 0.1 开发与维护入口

多语言共用同一组件、尺寸、字体角色和面板断点，不新增语言专属密度。工作台根节点声明实际语言；一级设置导航使用简洁单行名称（英文外观布局为 Appearance），二级页签和说明允许断行，操作名称保持完整。顶栏搜索在品牌、同步状态和操作按钮之间弹性分配剩余宽度，按控件实际宽度避让，不以固定左右预留宽度绝对定位。界面文字按源码静态文案与模板参数翻译，用户标题、正文、文件名、路径与自定义模式名称／说明保留原值。服务端确认由工作台补充的官方内置模式名称与说明跟随工作台语言，快捷输入与待办菜单共用翻译入口；不按模式ID或名称猜测自定义文案。日期及相对时间按实际工作台语言显示。设置中的语言选择沿用 Picker，与同排控件等高；统一保存生效，取消保留原语言。HTML 原型展示配置入口与布局基线，原型不连接宿主语言服务，不代表真实语言切换已经验收。

新增或调整界面先查本节，再查对应场景；同类控件复用已有组件和共享样式。共用规则只在本节维护，其他章节引用，不复制另一份尺寸表。新例外必须说明使用场景和理由，同时修改本节、视觉真源及相关组件；未确认的独立原型不能覆盖正式基线。

文字规范由本文件维护；可执行视觉规则在 `docs/ui/ui-directions.html`，主题令牌在 `src/client/theme.ts`，宿主适配在 `src/client/styles.css`。`prototype.css` 和 `prototype-icons.ts` 是生成物，不手改。文档与代码不符时先核对选择器优先级、生成物及宿主覆盖，再同步修正，不能把旧描述当成新的设计决定。

### 0.2 字体、颜色与边界

| 角色 | 统一规格 |
| --- | --- |
| 正文、按钮、普通输入与选项 | 14px；单行控件行高20px，正文按所在阅读区域 |
| 辅助说明、时间、状态、待办优先级、附件数量及文件大小 | 12px；不得在窄屏继续缩小 |
| 分区标题 | 16px／24px，字重600 |
| 弹窗标题 | 20px／28px，字重600 |
| 可编辑待办标题 | 16px、字重500；与普通字段区分 |
| 正常／中等／强调字重 | 400／500／600；选中导航使用600 |

控件与列表使用 `--font-ui`，阅读主题仅指定页面／章节标题使用阅读字体。正文用 `--text`，辅助与占位文字用 `--muted`，控件底色用 `--surface`，控件边框用 `--control-line`，普通分隔线用 `--line`。悬停、选中、主按钮、危险及焦点分别复用 `--hover`、`--selected-bg`／`--selected-text`、`--primary-bg`／`--on-primary`、`--danger-text`／`--focus-tone`。不在组件里写独立配色，状态同时提供文字或图标。

正式插件启动时，首帧使用本机缓存的已确认主题，再以服务端设置为准；无有效缓存时保留中性骨架和顶栏占位，读取设置后才显示顶栏，避免默认蓝色闪现。设置预览不写缓存，明暗状态实时读取宿主。

待办列表的优先级、创建信息和附件数量保持同一行；优先级与附件数量不收缩，创建信息在窄宽度时省略并提供完整悬停提示，字号仍为12px。待办正文容器宽度300px及以下，附件计数只显示图标和数字，宽度充足时显示「N 个附件」；悬停提示和读屏名称始终保留完整数量说明。

### 0.3 输入框与选择控件

官方「插件 → 终端」中的工作台扩展位于宿主页面，复用官方SettingsForm、SettingsValueField、Input、Button与Menu，不套工作台主题作用域。顺序为字体／字号／配色／预览／默认Shell／命令限制，底部唯一保存。标题16px／24px、说明12px，颜色使用宿主令牌。名称说明在左、所有输入和选择器在右且统一320px，字号与命令字段使用官方字段组件；650px及以下上下排列、控件全宽。字体直接点击输入框展开／搜索，箭头只作装饰，无独立按钮；不支持字体枚举或权限拒绝时保留输入。所有终端菜单跟随实时锚点等宽；字体菜单沿用固定320px高，配色与Shell菜单按内容自适应、最高320px，超出后内部滚动，低高度窗口受宿主可用空间限制。配色使用独立菜单类，不借用字体固定高度样式。官方Menu的className只用于锚点根，listClassName才用于portal菜单，禁止混用导致输入宽度及菜单高度失效。工作台「其他组件 → 终端扩展」仅展示默认关闭开关，不重复字段。

终端目录只使用官方条目，整页表单通过官方详情扩展挂载。宿主适配仅在`data-plugin-item-detail="shell"`内、扩展根节点实际存在时收起原`data-plugin-config`表单，不隐藏目录行、摘要或其他插件表单；扩展移除后自动恢复原表单。样式依赖`:has`并在接入前探测，缺失能力时保留原页面；不通过第二个同名目录注册实现页面覆盖。

字体输入下拉箭头复用官方`IconChevronDownOutlineRegular`（12px），在16px容器内垂直居中，右侧12px；不使用受字体基线影响的文本箭头字符。

终端字段不展示「已自定义」状态标签，自定义状态下只保留官方「恢复默认」操作；字号及命令执行限制共用此规则，字段校验与重置行为不变。

终端配色下载文字操作与官方「恢复默认」共用文字状态：默认使用宿主次级文字色，支持悬停时变为主文字色，无下划线、背景或尺寸变化。

字体首次枚举、失败与搜索空结果的提示放在固定高度菜单内部，不在输入框下临时新增表单行；字体菜单预留滚动条空间，异步列表载入不改变表单高度或菜单内容宽度。

终端独立配色位于字号后、预览前，复用同一320px控制列与官方Menu，预览仍紧随字体／配色设置。提供跟随平台、自定义和Catppuccin四种风格；下载按钮只生成草稿，不作为第二个保存入口。自定义展示背景／文字／光标／选区，16色ANSI字段折叠收纳，文字输入沿用官方Input并校验六位hex。预览展示文本与16色色样，这是颜色选择所需的局部配色例外，不将终端色板应用到设置页面或工作台主题。保存后更新终端显示层；关闭终端开关或选择跟随平台时恢复官方显示，保留已保存色板。

默认Shell保存后核对浏览器实际持久化结果；失败说明放在Shell控制列下，复用既有错误文字样式与统一保存失败反馈，保留选择草稿，不新增确认按钮。诊断标题中的用户会话名称与固定异常标签分开渲染，翻译只处理标签；恢复阻断原因逐项翻译，路径与其他用户数据保持原文。

工作台开关现统一命名「终端扩展」（Terminal extensions），官方插件目录及路径仍为「终端」（Terminal）。配色下载操作位于左列标题行最右端、选择框左侧，与官方字段恢复默认操作的位置一致；采用12px辅助文字，无背景、边框或按钮外观，保留按钮语义、键盘焦点、悬停下划线和禁用状态。配色说明与下载完成状态合为一个简短段落，宽面板不强制拆成两行，窄面板按可用宽度自然换行；失败提示仍单独显示。右列始终维持输入控制列宽。下载用短文案「下载 Catppuccin／重新下载」，读屏保留完整动作名。新增配色与预览文字跟随工作台语言，固定示例代码与色值保持原样；隔离演示提供配色语言切换，不代表真实语言与视觉已验收。

一致性按用途定义：同一用途的控件尺寸、边界和状态一致；紧凑工具栏与普通表单采用明确的两种密度。下表是现行基线，新增页面按对应类型复用。

| 类型 | 尺寸与排布 | 复用入口 |
| --- | --- | --- |
| 普通单行表单、目录输入 | 40px高、7px圆角、1px控件边框、上下9px／左右12px内边距；宽度服从表单列 | 原型基础输入样式；目录用 `DirectoryInput` |
| 普通表单下拉 | 与同排输入等高，通常40px／7px，左右12px；名称与箭头分开，长值单行省略 | `ui.tsx` 的 `Picker`／`.theme-select-trigger` |
| 设置右侧短字段 | 名称与位置等宽180px；650px及以下140px，480px及以下上下排列 | `.settings-text-control` 与设置 `Picker` |
| 待办添加／搜索复合输入 | 外框40px／10px，左内边距12px；内层输入无边框、无独立外圈；添加与搜索共用输入及宽度 | `TodoToolbar`／`.todo-input` |
| 待办完整新建、优先级筛选 | 与上项同排40px高，操作间距8px，切换前后保留占位；新建用7px圆角、中性控件边框和次要按钮配色，图标14px；筛选短文案「全部／未设置／高／中／低」，详情省略重复的「优先级」后缀 | `TodoToolbar` 的操作槽 |
| 统计／诊断分组搜索 | 外框36px／8px，左右10px，15px图标、图文间距8px；内层输入无边框 | `StatsProjectPanel`／`.stats-group-search` |
| 顶栏搜索 | 36px高，与同排添加项目、设置及同步按钮等高；保留现行7px圆角和宿主标题栏适配，输入与结果浮层等宽 | `Workbase`／`.global-search` |
| 待办标题与优先级 | 同排40px高；标题弹性，优先级160px，650px以下140px，480px以下字段换行 | `TodoDetail` 的标题字段与优先级 `Picker` |
| 待办多行描述 | 宽度填满内容区、基础7px圆角、左右12px内边距，按内容区设置最小高度；最小176px，可纵向调整；详情字段名「描述」、可访问名称「待办描述」、空内容「暂无描述」 | `TodoDetail`；Markdown预览为8px圆角阅读区域 |
| 备份文件选择 | 保留完整路径值，显示简洁名称；点击即可展开，无需先输入，列表最高320px | `RestoreSettings` 的集成下拉 |
| 会话快捷输入与模型等宿主控件 | 复用原输入卡及宿主组件的尺寸、文件与引用能力，不套普通表单高度 | `Composer`／`NativeComposer` |

普通文本输入支持直接编辑、粘贴与光标选择。目录输入点击文字区域只编辑；右侧文件夹按钮或 Alt + ↓ 打开宿主选择器，取消保留原值。选择型下拉点击即展开，不要求先输入内容或再点确认；确有搜索能力时输入用于筛选。标签与输入建立关联，placeholder只作示例，不能代替标签。

快捷输入的语音按钮复用官方 `conversation.input.activity` 组件，置于模型和发送之间；只在官方语音组件已挂载时显示。请求麦克风、录音、转写与反馈展开时隐藏添加／项目／模式及模型控件但保留挂载，活动区域使用工具栏剩余宽度，文本区与发送按钮仍可见，发送暂时禁用；收起后恢复原布局。按钮、波形、取消、停止、重试及准备提示沿用官方规格，不复制组件样式。textarea选区转换为宿主原子节点坐标，引用内部光标按官方投影规则移至该引用之后；版本冲突或超出20000字符时保留转写结果，用户调整后再插入。

同排控件按外框对齐，不通过单侧额外margin补偿。弹性字段使用 `min-width:0`，图标和固定操作不收缩；长值省略并提供全文提示，编辑区允许查看完整值。输入组内按钮使用明确的直属选择器，尺寸不能传播到浮层选项。

### 0.4 按钮与弹窗

### 0.5 状态、菜单与键盘

全局搜索的「全部／会话」分类在官方「历史会话搜索」实验套件启用且就绪时搜索标题和正文，不显示依赖提示。停用时只搜索标题；仅确认套件可用且未默认隐藏时，在列表下方复用`wb-help`提示添加启用，当前默认隐藏不提示。输入提示和页脚随实际搜索范围变化，待办内容统一称为「描述」，搜索提示与命中标签不再称「备注」。项目／待办分类不显示正文依赖、检索状态或报错。

普通输入与普通表单下拉聚焦统一中性 `--focus-tone` 边框及同色12%透明度的2px外圈；复合输入只在外框绘制，内层不得叠加边框、外圈或下划线。按钮保持可见键盘焦点，菜单使用内嵌焦点边界；紧凑项目导航、分支和宿主控件保留各自焦点规格。

项目列表、详情会话／待办的悬停及内部键盘聚焦使用`--entity-hover-bg`，直接引用官方侧栏及菜单的`--dsw-alias-interactive-bg-hover`；离线原型或宿主未提供令牌时，浅色回退`#2631480f`、深色回退`#ffffff14`。项目宫格外层始终使用官方`--dsw-alias-bg-base`（缺失时回退surface），不叠加悬停底色；采用飞书Base首页宫格的整卡上浮方式：细指针悬停或内部键盘焦点时`translateY(-4px)`，transform与阴影均300ms ease，离开平滑归位，不循环弹跳、不缩放、不改变布局占位。浅色阴影为`0 4px 16px 4px rgba(31,35,41,.03),0 4px 8px rgba(31,35,41,.02),0 2px 4px -4px rgba(31,35,41,.02)`；深色仅将阴影换为黑色20%／14%／12%，保证深底可辨。减少动态效果时取消位移与过渡，触屏不启用悬停上浮。内部统计小卡片及文件夹图标底块保持既有4%正文色混合surface的底色，悬停与内部聚焦均不变色，以整卡动效统一表达交互目标。项目列表仍在surface上叠色，会话／待办透明行叠在所在面板上。宿主主题变化自动生效，插件主题的文字及详情基础底色仍保留。悬停不额外加深边框、不使用主题选中底色。整体详情卡片仍为连续列表，不增加独立白底或内描边，既有轻分隔线保留；列表、按钮、菜单和危险操作不套项目宫格上浮动效。

首页统计卡按实际可见数量均分行宽，隐藏卡片不保留占位；以统计区域容器宽度响应，四卡在720px及以上保持四列，420–719px两列，419px及以下单列，1–3张按数量与现有两列断点适配。统计卡复用项目宫格的上浮距离、过渡、主题阴影和减少动态效果适配，保留原surface底色、line边框及文字，悬停、按下和键盘焦点均不变色；右下进入箭头仍按原规则出现。统计卡作为可点击明细入口，是上述「普通按钮不套宫格动效」的明确例外；内部数据、状态图标和明细打开行为保持既有实现。

技能、MCP、RSS扩展原型沿用上述统计卡规格，设置提供七项选择但最多开启六项；开启第七项时撤销本次勾选并就地提示「最多显示 6 张统计卡，请先关闭一项」，保留原六项。三种管理面板复用统计抽屉与二级页签，新增和刷新为操作按钮；导入导出统一集中到「导入与导出」二级菜单，列表工具栏不放导入／导出按钮。此页使用带图标、名称、说明与进入箭头的菜单行，复用统计分组导航，不使用操作卡片及独立文字按钮；点击菜单行进入现有导入／导出详情流程，返回保留菜单位置与草稿。有分组的页面沿用运行中／会话的两栏规格：左侧210px、900px以下180px，搜索固定在分组上方，分组列表独立滚动；分组与卡片区之间不显示竖线。窄面板搜索与分组选择器依次置于内容顶部，搜索只保留一个；无分组的页面省去左栏及窄屏选择器，搜索仍在内容工具栏，列表填满内容宽度。管理搜索复用36px统计搜索，普通编辑表单使用40px输入／下拉，操作使用36px按钮。

三类管理的技能、来源、市场、回收站、MCP连接及RSS订阅等内容统一使用卡片网格，复用主题surface、line与10px圆角；卡片展示图标、名称、说明、状态及辅助信息，整卡可点击，启停／刷新等快捷按钮独立响应。默认两列，无分组的宽面板三列，650px以下单列。点击卡片打开独立详情／配置弹窗，参考用户提供的市场卡片与配置弹窗截图：顶部返回、条目名称及关闭按钮，左侧分区导航，右侧正文独立滚动、底部操作固定。详情弹窗覆盖管理弹窗，底层保留菜单、分组、搜索及滚动但暂不可交互；返回或关闭详情后恢复列表和入口焦点。窄面板分区导航移至顶部横排；表单及按钮沿用40px／36px规格。详情进入编辑后取消返回详情并保留草稿；技能与RSS保存后返回列表，MCP保存后留在详情或继续授权。关闭详情不丢弃配置草稿；删除确认、OAuth演示及文章阅读继续在详情弹窗内切换。上述扩展目前只存在于视觉真源，正式插件仍为四卡。

扩展卡片信息按最新要求精简：只显示图标、名称、一行简短说明及一个常显操作，不再展示路径／地址、作用域、工具数量、检查时间或重复状态徽标。启停使用开关，直接复用设置页32×18px轨道、14px滑块及主题颜色，外层36px点击区域；开启时滑块在右侧，关闭时在左侧，支持键盘空格切换与焦点提示。市场未添加显示「添加」文字按钮，已添加记录同样使用开关；回收站显示「恢复」，文字按钮统一36px。导入／导出仅作为菜单入口，不展示操作卡片。异常仅保留可悬停及辅助技术读取的提示图标，详情承载完整状态与配置。操作点击不打开详情，卡片其他区域仍进入详情。启停后保留开关焦点，筛选移除当前条目时回到二级菜单。

MCP交互参考连接器中心实际源码的详情信息层级、工具折叠和状态操作。市场详情先展示名称、分类、说明、连接方式及认证类型，点击「配置并连接」进入表单；连接详情优先显示名称、作用域和状态摘要，异常就地提示。工具详情默认折叠并显示启用数量，展开后用36px共用搜索输入筛选名称及说明；每个工具按需展开说明和参数结构，连接不可用时禁用工具开关并解释原因。开关变更保留工具搜索、正文滚动、当前参数展开和焦点。底部主按钮按当前状态显示「启用连接／重新授权／重新连接／查看工具」，连接中禁用重复操作。首次OAuth配置保存后进入等待授权页，取消回到详情且保留配置，模拟成功后展开工具。真实OAuth是否打开外部授权页仍由服务协议决定。

统计与诊断右侧记录统一上下16px、左右12px内边距，窄面板保留左右留白；诊断标题行与记录文字对齐。记录标题及辅助信息单行省略并提供全文悬停提示，操作按钮不收缩。会话与待办统计记录只显示标题和时间，不重复项目／文件夹名称或路径，项目身份由左侧分组承载。诊断记录显示项目、异常类型、短原因及独立一行的完整session ID；ID采用12px等宽字体，可选择复制，窄屏允许换行且不截取／省略。完整原因、路径及母会话标识保留在辅助信息提示与搜索中。

从统计点击待办直接复用`TodoDetail`，详情显示期间隐藏统计弹窗并暂停其焦点管理，保留统计组件、项目分组、搜索词及滚动状态。关闭或成功保存后恢复统计弹窗及原点击项焦点；保存失败继续保留详情与草稿。仅统计入口采用保存后关闭，项目页待办保持原保存后预览行为；项目或待办已经消失时禁用写入并保留关闭入口。

统计弹窗暂隐藏采用`visibility:hidden`并禁用指针交互，保留布局与已完成的入场动画；返回原列表时直接恢复可见，不重播抽屉／遮罩入场动画，滚动与焦点在绘制前恢复。首次打开统计仍保留原入场动效。

待办附件选择、拖入或粘贴后直接上传，不增加二次确认。已有待办的附件独立保存，正文草稿仍通过底栏「保存」提交；新建待办标题为空时先保留文件并说明原因，结束有效标题编辑后自动继续。上传中显示进度并锁定关闭和重复操作，失败文件可移除或单独「重试上传」，成功文件不重复上传；底栏保持「保存」文案，不使用「保存并上传」。

`Menu`、`Picker`与备份文件下拉复用`ui.tsx`的`usePopup`。操作菜单打开聚焦首个可用项，选择菜单优先聚焦当前选中项；列表异步到达时仅在焦点仍在入口处补聚焦，不抢走已有选项焦点。方向键、Home／End跳过禁用项；无当前项时向下从首项、向上从末项开始。Esc／Tab阻止本次默认事件并关闭最内层菜单，返回入口；下一次Tab按正常页面或弹窗顺序移动。

窗口、面板、触发器或菜单内容尺寸变化时重新定位，不因resize丢失菜单；外部滚动关闭，菜单内部滚动保留。点击外部关闭但不抢走点击目标焦点；触发器变为禁用时立即移除选项，重新启用后保持关闭。备份空列表仍可Esc／Tab返回入口。

全局搜索保留输入框焦点，用`aria-activedescendant`关联选中结果，`aria-controls`指向实际listbox；焦点移出搜索区域时关闭结果。弹窗Tab循环，关闭返回入口；Esc先关闭最内层下拉。所有输入和图标操作具有可访问名称，错误和任务进度可播报，不能只靠颜色表达。

### 0.6 响应式、复用与验收

宽度断点使用工作台容器宽度；`pointer`、`hover`与减少动态效果仍属于能力查询。窄屏先调整列数、宽度、换行和辅助文案，不另写一套小字号。同排固定操作保留占位，360px面板不得横向溢出；减少动态效果时取消非必要过渡。

开发提交前逐项核对：

1. 控件用途和复用入口来自本节，同类尺寸不另写局部变体。
2. 修改共用规格时同步真源与全部使用处，检查动态类名、选择器优先级、组合按钮与嵌套菜单。
3. 核对全部主题的明暗外观，以及360px、650px边界和常规宽度；检查正常、焦点、禁用、长值、空值、失败及处理中。
4. 验证键盘、输入法、取消、草稿保留和错误重试；状态样式不能改变写入或上传限制。
5. 代码改动运行typecheck、测试和构建；生成逻辑改动另核对CSS不变量及构建幂等性。浏览器验收测量外框尺寸和computed style，真实宿主验收独立记录，不用单元测试代替视觉结论。

### 0.7 现有差异与适用边界

普通输入及普通表单下拉统一使用 `--control-radius:7px`，共用规则覆盖历史温暖主题的通用按钮圆角；复合待办输入为10px、统计搜索为8px，内层输入不套普通控件圆角。项目导航、分支、开关、文件上传及宿主会话输入保留独立规格；新增同类控件不得自行更换。今后调整输入尺寸或圆角，应作为一次共用样式改动同步全部同类控件，并更新本节。具体已验证范围只记在开发日志，代码完成不代表已安装或已在真实宿主验收。

宿主分支条沿用官方28px控件与13px文字，分支列表及说明12px；插件更新的新旧版本代码沿用官方13px等宽字，状态、说明与失败提示12px。此类宿主规格仅用于对应适配区域，不传播到普通表单、列表操作或保存提示。

## 2. 首页

### 快捷输入与最近会话

正式快捷输入保留原型中的圆角输入卡和 textarea；复用 Harness 官方添加菜单、项目菜单、模型控件及输入服务，不嵌入 `conversation.content` 工厂。添加菜单沿用宿主主题，通过独立浮层按面板可用空间向下或向上展开，避免顶部输入卡压缩菜单高度；输入卡与项目、模式触发按钮仍使用工作台主题令牌。项目菜单沿用官方文件夹图标，仅显示项目名，提示也不显示路径；归档与不可用项目禁用。模式弹窗展示官方预设名称、说明和可用项，自定义预设保留自身文案。模型控件与添加菜单共享 SessionProvider，沿用官方提供商、模型和推理强度菜单，选择提交期间禁用发送；不在发送时重新选择模型。模型区最大宽240px，面板不超过600px时收至120px，不超过420px时使用官方紧凑图标。

输入宽度与最大 1120px 统计区域共用基准，常规为其 6/7，最大 960px、最小 640px；空间不足时下限收至可用区域减 32px。始终居中且无横向溢出。

快捷输入项目与模型弹窗固定从按钮下方8px展开，最多360px高；以工作台和可见视口交集中的下方空间为限，底部保留8px，不自动向上翻转。项目沿用官方列表滚动层，模型列表保留顶部搜索框与分组内部滚动；模型根菜单、模型列表和推理强度页切换后重新定位，滚动与窗口大小变化时同步。仅调整当前快捷输入关联的浮层，不影响宿主会话页菜单。

文件拖入作用于整张输入卡，使用主题强调色内描边，空输入提示「松开以添加文件或图片」；离开、放下、切换项目／模式或进入提交状态后恢复。支持剪贴板图片，与文字同时粘贴时在选区插入文字并保留剩余正文。拖入、粘贴及菜单选文件共享官方导入入口：桌面普通文件／目录生成路径引用，图片上传，附件按钮显示上传状态，失败时提供「重试上传」。拒绝提示不清空草稿，普通文字拖入／粘贴不被文件事件拦截。

工具行左侧依次是添加、项目、模式，右侧是模型、发送；下方分支条跟随官方 `dsh-experimental-forge-bundle` 启停，启用并挂载 forgePanel 时显示、禁用时整体隐藏。原型显示分支条时代表 Forge 已启用。原有容器响应式、输入圆角和宽度不变。添加弹窗锚定输入卡，附件和引用交给官方输入服务处理；旧首消息失败重试保留原有幂等链路。

最近会话使用按钮形态且输入框可见时，按钮居中贴近输入框下方，外边距统一由 `--home-shortcuts-gap:12px` 定义；输入卡的下边距归零，避免叠加间隔。卡片形态与隐藏输入框时的排布保持各自区块间距。详情页会话列表及会话空状态共用首页的圆形气泡图标，尺寸与颜色保留详情页规范。

设置中的最近会话样式选项仅显示「卡片」与「按钮」，不在选项名中显示数量。添加项目弹窗使用「打开已有项目」标签；字段为「项目路径」，输入框提示「输入或粘贴项目路径」，下方提示「也可点击右侧图标选择项目。」。输入框可直接编辑和粘贴，文字光标，不因点击打开选择器；右侧图标与 Alt + ↓ 提供项目目录选择。

最近会话无区域标题：卡片最多 5 张，最小高 60px、12px 圆角，左侧 28px 轻色底块内放 16px 圆形气泡，右侧 14px／500 字重标题与 12px 项目名，居中限宽 1120px；进入箭头保留占位，悬停或键盘聚焦时显示，触屏常显。按钮高 32px、10px 圆角、主题细边框，使用 14px 同款圆形气泡，固定单行、长标题省略并提供全文提示；根据可用宽度、各按钮实测宽度与 8px 间距显示完整连续前缀，宽屏可超过 3 个。按钮区域与输入卡共用外宽规则，左右内边距为 `clamp(24px,5%,48px)`，居中排列，隐藏的候选不可聚焦。卡片按面板宽度变为 5／3／2／1 列，条目数据不截断。没有会话时隐藏整个可选区域，不显示占位提示。悬停、按下和焦点共用主题令牌。

### 统计与项目

四张统计卡对应运行中、所选时间范围内的会话（默认7天）、未完成待办、诊断，各自可点击进入明细。最小高104px、12px圆角，标签、26px数值与辅助说明左对齐；右上角图标为24px框内18px图形，无彩色色块；会话统计使用圆形气泡。诊断主值为目录／缓存／孤儿／空会话四类异常记录总数，与其他卡片共用字号、字重及正文颜色；下方仅显示非零类别数量，完整无异常时显示「检查正常」，缺少能力或失败时显示「检查未完成」。仅状态图标使用主题成功／危险／中性色，不将读取中的状态显示为成功。诊断页「重新检查」按钮位于标题同一行右侧，复用「添加技能」的36px主按钮，图标、字号、圆角、间距及状态均遵守第0节；说明及横线保留在下方，仅在有缓存或孤儿修复候选时显示紧凑操作栏，空会话批量操作放在右侧操作区，不重复显示分类标题。每条记录的修复操作独立成按钮，不嵌套按钮。窄面板检查状态改为上下排列，共用主题边框、面板、文字及危险色。箭头在右下角保留位置，仅悬停或键盘聚焦显示；减少动态效果偏好下取消过渡。窄面板统计切换为两列。

扩展视觉真源增加技能、MCP、RSS三个可选卡片。技能主值为已启用全局技能，项目与异常数量作为辅助；MCP主值为已连接数，配置总数和异常作为辅助；RSS主值为订阅源数，检查失败数量作为辅助。保留旧设置，新项默认关闭；预览工具栏提供「六卡预览」，一次显示运行中、待办、诊断及三项扩展，仍可在设置中替换。

扩展统计区域最大1440px，独立命名容器 `workbase-stats` 按区域宽度响应：5–6卡在1140px及以上按数量均分、720–1139px三列；四卡在720px及以上保持四列；所有多卡在420–719px最多两列、419px及以下单列，实际列数不超过开启卡片数。卡片间距12px，未满的末行不拉伸成整行；统计抽屉与设置抽屉同宽（左右各留50px、最宽1580px），输入卡与最近会话保留原宽度基准。

技能二级菜单为「全局技能／项目技能／技能来源／技能市场／回收站」，标题按钮固定「添加技能」。全局技能按来源分组，项目技能按项目分组；技能来源只展示目录、启用开关与「添加路径」，不展示具体技能，不加分组。技能市场、回收站不分组；回收站提供恢复和永久删除，确认文字区分移入回收站与永久删除。

MCP二级菜单为「我的连接／MCP 市场／市场来源」，标题按钮固定「添加链接」。我的连接按已启用／已停用分组，连接状态独立展示；MCP市场按分类分组，市场来源不分组，提供「添加来源」和来源开关。工具开关仍在连接详情中。

RSS二级菜单为「我的订阅／推荐订阅源／导入与导出」，标题按钮始终「添加订阅」。我的订阅使用自定义分组及「未分组」；「自定义分组」标题右侧使用36px加号图标入口添加分组，选中自定义分组时显示同尺寸编辑图标，均有悬停提示及可访问名称。分组标题与操作固定在搜索下方，分组列表独立滚动；窄面板保留标题操作并使用分组选择器。右侧列表不提供刷新及设置按钮，单订阅详情保留刷新。移除分组保留订阅；分组编辑复用普通表单，订阅分组复用共用选择器。推荐订阅源不分组；导入与导出页不加分组或搜索栏，通过共用菜单行进入OPML流程。文章从订阅详情进入详情弹窗，返回后恢复原列表。

新增与编辑、启停、移除确认、导入候选预览、配置／OPML导出、OAuth等待／取消／完成和文章阅读在原型内可操作，数据单独保存到浏览器；目录扫描、外部连接、真实授权、定时刷新及订阅网络请求均未接入。

项目工具栏统一放标题、互斥活跃／归档／收藏、字段设置及宫格／列表切换，不显示右侧活动或排序说明。默认宫格，项目总览占满下方宽度。

项目宫格头部为文件夹图标和两行信息：第一行名称与可选状态，第二行目录和有效最近活动相邻，以中性细线分隔；更多留右侧。中间统计按开启字段自适应，底部仅在有最近会话时显示。没有活动时间时隐藏活动及分隔符；有效零值统计保留。隐藏字段不留空区域，长内容省略并保留全文。

项目宫格、列表及详情名称前的文件夹使用官方工作区展开态 `IconFolderOpenRegular` 的图形，保留原有图标框尺寸与主题颜色；运行中、目录异常仍使用相应状态图标。文件夹图形在原型中统一定义，目录选择等共用入口同步使用。

宫格和列表的目录辅助行使用 2×2 实心四圆点，单点直径 2.4px，中心位于 14×14 图标框的 (4,4)、(10,4)、(4,10)、(10,10)。图标框和目录文字均为 14px、图文间距 2px，在 18px 行高内垂直居中，颜色继承辅助文字，不显示 `/` 前缀。图标不收缩，目录名称独立收缩省略，点击仍复制完整路径。

列表表头与行共用列模板，项目名和目录为主要信息，辅助列顺序为近期活跃、待办、归档、最近会话、最近活动、状态，更多固定末列。隐藏字段删除整列，桌面字段过多只允许列表区域横向滚动，窄屏辅助字段按标签和值换行。

正常项目不常驻「目录可用」文字。状态字段关闭后以图标和完整无障碍描述保留状态；收藏中的归档内容仍显示只读标识。

## 3. 项目详情

### 头部与分栏

第一行「主页 › 项目图标 项目名称」，主页及项目名 15px，项目图标 22px，右侧更多。名称点击重命名，悬停／聚焦显示淡色铅笔；归档名称只读，详情不显示置顶。

第二行左侧「四圆点 目录名称 ▾ | 最近活动 · 时间」，与首页相同的 14px 实心四圆点图标、14px 目录文字和 12px 箭头放在同一目录选择按钮内，18px 行高，图文间距 2px、箭头间距 6px，垂直居中，不显示 `/` 前缀；不在按钮外另放文件夹。项目名称前仍使用官方文件夹图标。两行间距 4px，统一左边界。目录点击切换，图标不收缩，名称独立收缩省略，完整路径通过提示和菜单展示；复制完整路径在更多菜单。

第二行右侧为唯一列表／整体卡片切换，同时控制会话与待办。左侧允许收缩省略，切换控件不被挤出，不增加工具行。

默认会话 65%、待办 35%，保存范围为会话 40–70%。24px 分隔交互区支持拖动及方向键每次 2 个百分点，Home 恢复 65:35，End 到 70:30。已有比例保留，取消与保存失败恢复旧值。

双栏最低内容宽度为会话 280px、待办 240px；850px 及以下切「会话／待办」页签。页签保留 DOM、草稿、选中和滚动，未选面板不进入键盘序列；搜索待办自动切对应页签。

常规桌面详情填满可用视口，头部、两栏标题及工具行固定，仅列表独立滚动。按实际视口和软键盘计算余高；余高不足 260px 时允许主内容滚动并保留 360px 列表区域，避免操作被裁切。

### 列表与整体卡片

列表模式两栏开放排布；卡片模式分别将标题、工具行和列表包在整体卡片中。两栏共用 panel 底色、细边框、10px 圆角、12px 内边距，无阴影，拉伸至相同高度。条目仍为普通列表行。

两栏标题行及工具基线对齐，取消单侧顶部补偿和中间重复装饰竖线。拖动柄仅悬停、聚焦或拖动时显示，原交互区保留。

会话标题和待办标题均为单行省略。会话隐藏摘要，保留时间及状态；待办保留来源及时间，辅助文字使用第0节的12px，不通过降低透明度使文字难读。全文由提示、编辑或详情入口查看。

会话置顶紧跟标题，6px 间距并垂直居中；标题按内容收缩，置顶占位稳定。项目／会话置顶仅悬停或键盘聚焦显示，已置顶也遵循该规则；触控稳定可达。收藏只在更多菜单，不显示常驻星标或重复置顶菜单。

会话与待办悬停及键盘聚焦背景统一使用主题 hover。任务行约 56px 最小高、8px 上下内边距、5px 圆角；当前精确尺寸和图标以原型 CSS 为准。辅助信息遵循第0节的12px规格。

### 待办分组

待办标题输入保留 Enter 快速创建，旁边提供「完整新建」。行首完成、中间标题打开详情、行尾删除；辅助行依次显示可选优先级、来源时间、附件数量，不在列表或卡片展示备注正文，备注仍可搜索。待处理按高／中／低／未设置排序，同级按更新时间倒序；添加与搜索共用同一输入框，右侧完整新建与优先级筛选原位切换，操作占位稳定。删除按钮仅当前行悬停或键盘聚焦时显示，保留占位避免文字跳动；触屏常显，点击直接删除并提供 5 秒撤销。待处理使用轻量 16px 圆圈，悬停／聚焦可用完成按钮时出现淡勾号，已完成用圆圈内勾；分组展开箭头和完成图形明确区分。

完整新建和详情共用唯一居中弹窗，尺寸、标题栏、底栏和控件密度见第0节，仅内容区滚动。状态只读，项目和创建信息紧接header下方，标题与优先级在其后同排；描述与附件集中在同一内容区域，不分菜单。优先级复用主题下拉，显示色点和选中勾；描述只用一个编辑／预览切换，底层沿用`note`字段。关闭只在右上角，底栏左侧保存状态、右侧模式与发起会话组合按钮和保存按钮；400px以下隐藏保存状态避免溢出。不提供评论、变更记录或截止日期。

附件不限制格式；图片缩略图失败回退文件图标，其他文件显示名称、大小与下载。最多10个、单个10MiB，支持选择、拖入、粘贴、移除及失败续传。未上传附件禁止发起会话，草稿不会自动发送。全部样式使用工作台 surface、panel、text、muted、line、accent、danger、success 等令牌，适配跟随宿主、DSH、清爽、温暖阅读和紫晶的明暗外观。布局规则修改真源，宿主覆盖仅处理通用弹窗样式优先级。

「待处理」「已完成」始终可见，显示数量；默认待处理展开，已完成入口在底部。点击任何分组只展开该组，点击已展开组则切另一组，空组仍保留入口和空态。网格高度与箭头约 200ms 过渡，减少动态效果时立即切换。

两组分别独立滚动、按项目记忆，收起面板 inert 且不参与焦点。完成／重新打开不自动切组，保留连续操作焦点；搜索或统计定位先展开目标组，再滚动、高亮和聚焦。状态变更撤销入口不因普通提示丢失。

布局切换与置顶选中仅用底色和图标色，不叠加描边或内阴影，键盘焦点保留。输入聚焦用中性细边框与淡外圈，复合输入只在外容器提示，不叠加内层下划线。运行／异常／归档结合图形及文字或无障碍说明，不只依赖颜色。

桌面主要更多、完成和布局操作以 32px 为目标，触控 44px；桌面置顶为 24px，触控稳定显示并扩大目标。详情文字与控件使用 UI 字体，温暖主题仅页面和章节标题使用阅读字体。图标直接同步原型 SVG。

## 5. 抽屉、菜单与搜索

弹窗底栏按钮、标题栏及输入控件统一遵守第0节，主次与危险颜色仍使用各自主题令牌。

统计待办页标题右侧提供「添加待办」，与「添加技能」「重新检查」共用36px主按钮规格。点击复用待办编辑器打开创建弹窗，默认当前分组项目（全部项目时用当前活跃项目或首个活跃项目），可通过共用选择器改选其他活跃项目。无活跃项目或读取中禁用创建入口；关闭恢复原统计列表，保存后刷新列表及首页待办数，保留分组、搜索、滚动和添加入口焦点。创建与现有待办详情分别处理返回，避免把新增任务误判为原待办消失。

设置及统计使用第0节定义的底部抽屉；只保留顶部16px圆角，约300ms上滑，减少动态效果时取消动画。设置标题和底栏固定，中间独立滚动；统计概览不设横向footer，内容区延伸至底部，左侧分类与底部操作分区，关闭入口位于侧栏底部并用主题横线分隔，同时保留右上角关闭按钮。窄屏使用顶部分类，侧栏底部关闭入口隐藏，由右上角关闭；考虑安全区域。统计中的详情／编辑弹窗继续保留保存等必要操作栏。两类弹窗共用尺寸变量。

运行中、会话与待办页内采用项目分组导航：左列210px，900px以下180px，含项目搜索、全部项目、项目名及记录数量，路径只保留悬停提示；右侧直接显示可打开的记录，无重复标题、路径和总数。两列间去除竖线，分类标题为普通16px文字，说明下方留16px内边距并显示1px主题边界横线，无主色短线或二级菜单。搜索框及外层聚焦遵守第0节，弹窗通用表单标签的纵向样式不作用于此搜索框。宽面板分组列表与记录独立滚动，650px以下上下排列，项目列表最高180px、内容随抽屉正文滚动。搜索支持项目名和路径，同名项目按身份区分；文字、选中和悬停遵守共用规范。

诊断复用上述布局，导航固定为「全部异常／目录异常／列表缓存／孤儿子代理／空会话」，显示异常数量，零异常类别仍可选择；项目不再作为诊断分组维度。顶部「重新检查」与技能页「添加技能」复用同一36px主按钮规格，14px文字、8px圆角、7px／12px内边距，颜色、图标、间距、悬停及禁用状态沿用共用主按钮，不另设诊断按钮变体。右侧内容区不重复显示分类标题、数量及标题下分隔线，直接呈现结果或空状态；类别与数量已在左侧导航表达，内容区保留随筛选更新的辅助技术标签。搜索异常内容、项目、路径与会话标识，右侧记录保留归属与路径，空类别据实际检查状态显示正常、能力不可用或未完成。空会话批量删除作为右侧操作，不附加重复分类标题；范围不受搜索条件影响，执行前确认范围，跳过正在使用或状态变化的记录。

插件批量更新使用官方Modal、Button和StateDot，仅展示用户profile安装的非官方插件。确认阶段逐项显示13px等宽新旧版本对照，旧版本用辅助色；版本区使用官方模块背景、圆角与箭头，下方显示安装源及更新期间短暂停止、失败时保留或重装旧版本的说明。列表独立滚动，头部和确认按钮固定，进度与结果保留来源、恢复、失败输出及需重启提示。

设置五分类依次为通用配置、外观布局、项目配置、备份恢复、其他组件；图标分别为设置、调色盘、开口文件夹、归档盒、组件积木。外观布局合并原外观配置与首页显示，复用共享二级页签呈现「首页模块／统计卡片／主题配色」，默认首页模块；数据统计关闭时隐藏统计卡片页签，保留卡片与时间范围配置，不新增第三层导航。打开设置默认进入通用配置。备份恢复紧邻其他组件上方，包含「数据备份／数据恢复／执行状态」，复用现有二级页签样式与键盘导航；默认数据备份，执行状态分区展示备份与恢复结果，切换时保留操作表单和任务订阅。项目配置包含全局配置与项目配置。其他组件与项目专属设置展示对应图标的空状态。明暗提示放在主题配色页签内、主题卡上方，颜色跟随主题；主题卡桌面两列、窄屏单列，五个选项自然换行。主题即时预览，保存保留、取消恢复，跨分类与页签草稿保留，统一保存。统计卡继续进入统一工作台概览。

字号按角色统一：设置项、表单标签和一二级菜单 14px（未选中500、选中600），辅助说明、时间、状态12px，分区标题16px，弹窗标题20px；窄面板不缩小字号。侧栏名称和位置控件右对齐等宽，480px以下上下排列。统计卡片页签不加从属缩进竖线；最近会话样式与侧栏设置保留从属层级。窄面板一级导航按可用宽度自动分列。

通用设置首项为「启动桌面端时打开工作台」，使用与其他设置一致的主题开关，说明保存后下次启动生效；默认关闭。设置保存与取消沿用统一事务，不即时切换主页面。

默认项目根目录与已有项目目录使用 `DirectoryInput`，点击输入框只编辑或粘贴路径；文件夹按钮或 Alt + ↓ 打开宿主本地目录选择器。取消选择保留原值，失败在字段下提示；选择中禁用提交。HTML 原型展示明确标注的模拟目录列表。

菜单继承主题底色、边界和状态，受实际视口限制，低高度内部滚动。普通项目选项显示名称与完整路径，重名可辨；快捷输入项目菜单仅显示名称并沿用官方菜单键盘交互。工作台自有菜单的宽度、打开焦点、键盘、禁用和尺寸变化行为遵循第0节。

更多菜单与字段菜单使用整行悬停背景 `--hover`，键盘焦点使用 `--focus-tone` 的内嵌边框；常用操作与项目管理分组，危险操作独立分组并使用 `--danger-text` 与面板混合出的淡色底纹。字段开启由主题色复选框表达，关闭不弱化整行文字，点击后保持展开；16px 复选框固定右侧，名称独立收缩。尺寸、行高与字号见第0节，受工作台面板边界限制。标题与视图工具栏的图标尺寸只应用于直属按钮，避免嵌套菜单项缩成图标宽度。

详情页项目选择器属于带说明的菜单，宽度遵守第0节：上方14px半粗项目名，下方12px等宽完整路径；两行各自禁止换行、超长省略，悬停提示完整路径。选中使用 `--selected-bg` 与 `--selected-text`，触发按钮仍为四圆点与目录名。

会话预览与待办详情共用第0节定义的居中弹窗。header直接显示会话名称，单行省略，悬停展示全文，不显示「会话预览」标签；状态附带图标，与项目、更新时间合并在header下方摘要区。标题区、摘要与底部操作固定；正文占据剩余空间并独立滚动，短内容也保留统一外框尺寸。无正文、读取中、失败提供明确说明，失败可重新读取；底部提供关闭与打开会话。所有颜色来自主题令牌，适配跟随宿主、DSH 默认、清爽、温暖阅读、紫晶的明暗外观。

搜索悬停／聚焦／有关键词时加长，空关键词时展示搜索范围提示，输入框和浮层等宽、同左边缘，下方间隔8px。结果按下方剩余高度限制并独立滚动；离开搜索区域关闭结果、保留关键词。自有选择菜单的尺寸变化行为见第0节。

结果按项目／会话／待办分组，显示归属、真实摘录及归档／完成状态。宿主不提供命中数或消息定位时按当前限制说明，不用示例结果伪造真实能力。`⌘K / Ctrl+K` 聚焦、方向键选择、Enter 打开、Esc 保留词关闭。

弹窗及遮罩仅覆盖插件工作台显示区域，不覆盖或锁定宿主侧栏。设置抽屉按工作台高度计算，顶部预留 50px、底部贴齐；菜单和选择器定位限制在当前弹窗、工作台与视口交集内，内留 8px，靠底向上展开。打开弹窗只锁定工作台背景，Tab 在弹窗内循环，关闭恢复入口；下拉菜单的 Escape 先关闭下拉。列表重绘按实体或动作恢复焦点。长文本详情可选择复制，剪贴板失败仍能查看完整路径。

自有选择器和操作菜单宽度遵守第0节；快捷输入的官方项目与模型菜单沿用宿主规格。HTML原型模型列表仅为示例，推理强度以正式宿主控件为准。侧栏位置统一列「顺序第1／2／3个」及「倒序第1／2／3个」；名称与位置控件等宽右对齐，选项不增加控件宽度。

## 6. 异常、写入与验收

Toast 位于工作台顶部中央（距面板顶部68px），最大宽度520px，左右至少16px；文字使用第0节的14px正文规格、20px行高、10px圆角。背景为96% `--surface` 与4% `--primary-bg`混合，文字用`--text`，边框用`--line`；成功图标用`--success`、信息图标用主题主色。关闭用28px图标按钮，悬停与焦点使用主题令牌；较长文案可换行。层级高于工作台模态遮罩，弹窗开启时提示不设为inert；成功显示3.5秒，信息根据字数显示5–10秒，相同文案再次触发重计时。提示用礼貌状态播报，不自动夺焦点。

空、加载、错误在对应区域展示，失败保留成功数据；顶部同步失败提示数据可能过期并提供刷新。目录异常持续说明原因，待办和历史记录不丢失；归档内容业务只读，个人收藏／置顶不解除限制。

创建、编辑、归档、移除、删除、设置及布局只在保存成功后反馈成功或关闭；失败保留输入和原状态。当前宿主受阻的项目归档、迁移、永久删除不得因为原型存在而宣称实现。

实现按原型进行 1:1 核对，覆盖页面布局、SVG、控件尺寸、菜单、弹窗、悬停与焦点。现有 [插件视觉报告](ui/verification/index.html) 覆盖 DSH／清爽／温暖阅读及不同宽度，是对应版本的证据；不代表紫晶或真实桌面已经视觉验收。

当前验证范围、重跑方式和剩余差异见 [开发日志](../.agents/notes/dev-log.md)。HTML 原型保留，旧原型 PNG 与修订过程不再作为现行设计说明。
