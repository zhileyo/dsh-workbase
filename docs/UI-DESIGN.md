# DSH Workbase · UI 设计规范

更新日期：2026-11-06。合并 r43 及此前已确认的有效规则，并同步 0.2.4 顶栏和目录选择交互。需求见 [PRD](PRD.md)，可交互视觉基线为 [ui-directions.html](ui/ui-directions.html)。

## 1. 布局与信息层级

工作台使用宿主的可用宽度，内部无固定侧栏、图标轨道或项目导航列，不设置 1440px 最大宽度。首页、详情共享 Header，项目切换使用详情目录下拉。

Web Header 高 64px；macOS 桌面 Header 高 48px、搜索框高 32px，与宿主标题栏对齐。左侧使用宿主 `--dsh-frame-leading-clearance` 预留窗口控制区，侧栏收起仍不重叠。搜索占弹性区域，右侧同步、有效最近活动、添加项目和设置保持可达。窄屏隐藏辅助文字和按钮文案，保留图标、提示和无障碍名称，搜索不得挤出操作。

品牌区使用工作台图标和「工作台」，移除重复 Harness 名称与分隔线，搜索宽度上限 720px。会话页使用宿主 `conversation.header.leading` 插槽，在系统控件后提供「工作台」按钮，返回保留的工作台页面，不改变会话或清空输入。

首页由居中快捷输入、最近会话、可选统计和下方全宽项目总览组成。四模块可独立隐藏；全部关闭时展示恢复设置提示。主要文字突出项目名和任务标题，目录、来源、状态与时间使用较轻层级。

## 2. 首页

### 快捷输入与最近会话

输入面板参考 Harness 一体式输入框：28px 圆角、轻阴影、无内部重复分割线，正文初始 52px，自动增高至 180px，超长内部滚动，无手动拖拽柄。

输入宽度与最大 1120px 统计区域共用基准，常规为其 6/7，最大 960px、最小 640px；空间不足时下限收至可用区域减 32px。始终居中且无横向溢出。

底部左侧项目和模式，右侧模型和 34px 圆形发送。选择器高 28px、无边框，项目选项显示名称与完整目录。所有宽度下维持一行，600px 以下缩小间距并省略长名，短项目名不扩张占位。

最近会话无区域标题：卡片最多 5 张，高 64px，左图标、右标题与项目名，居中限宽 1120px，桌面额外留白；按钮最多 3 个，高 32px，胶囊圆角、固定单行、长标题省略并提供全文提示。卡片允许窄屏折行，条目数据不截断。没有会话时隐藏整个可选区域，不显示占位提示。

### 统计与项目

四张统计卡对应运行中、最近 7 天会话、未完成待办、诊断，各自可点击进入明细。桌面最小高 116px，图标、名称、数值与辅助说明层级明确；箭头仅悬停或键盘聚焦显示，并预留空间。具体圆角跟随主题，温暖阅读为 5px，其他独立主题为 16px。

项目工具栏统一放标题、互斥活跃／归档／收藏、字段设置及宫格／列表切换，不显示右侧活动或排序说明。默认宫格，项目总览占满下方宽度。

项目宫格头部为文件夹图标和两行信息：第一行名称与可选状态，第二行目录和有效最近活动相邻，以中性细线分隔；更多留右侧。中间统计按开启字段自适应，底部仅在有最近会话时显示。没有活动时间时隐藏活动及分隔符；有效零值统计保留。隐藏字段不留空区域，长内容省略并保留全文。

列表表头与行共用列模板，项目名和目录为主要信息，辅助列顺序为近期活跃、待办、归档、最近会话、最近活动、状态，更多固定末列。隐藏字段删除整列，桌面字段过多只允许列表区域横向滚动，窄屏辅助字段按标签和值换行。

正常项目不常驻「目录可用」文字。状态字段关闭后以图标和完整无障碍描述保留状态；收藏中的归档内容仍显示只读标识。

## 3. 项目详情

### 头部与分栏

第一行「主页 › 项目图标 项目名称」，主页及项目名 15px，项目图标 22px，右侧更多。名称点击重命名，悬停／聚焦显示淡色铅笔；归档名称只读，详情不显示置顶。

第二行左侧「文件夹图标 :: 文件夹名称 ▾ | 最近活动 · 时间」，12px 辅助文字，两行间距 4px，统一左边界。目录点击切换，完整路径通过提示和菜单展示；复制完整路径在更多菜单。

第二行右侧为唯一列表／整体卡片切换，同时控制会话与待办。左侧允许收缩省略，切换控件不被挤出，不增加工具行。

默认会话 65%、待办 35%，保存范围为会话 40–70%。24px 分隔交互区支持拖动及方向键每次 2 个百分点，Home 恢复 65:35，End 到 70:30。已有比例保留，取消与保存失败恢复旧值。

双栏最低内容宽度为会话 280px、待办 240px；850px 及以下切「会话／待办」页签。页签保留 DOM、草稿、选中和滚动，未选面板不进入键盘序列；搜索待办自动切对应页签。

常规桌面详情填满可用视口，头部、两栏标题及工具行固定，仅列表独立滚动。按实际视口和软键盘计算余高；余高不足 260px 时允许主内容滚动并保留 360px 列表区域，避免操作被裁切。

### 列表与整体卡片

列表模式两栏开放排布；卡片模式分别将标题、工具行和列表包在整体卡片中。两栏共用 panel 底色、细边框、10px 圆角、12px 内边距，无阴影，拉伸至相同高度。条目仍为普通列表行。

两栏标题行及工具基线对齐，取消单侧顶部补偿和中间重复装饰竖线。拖动柄仅悬停、聚焦或拖动时显示，原交互区保留。

会话标题和待办标题均为单行省略。会话隐藏摘要，保留时间及状态；待办保留来源及时间，辅助文字至少 11px，不通过降低透明度使文字难读。全文由提示、编辑或详情入口查看。

会话置顶紧跟标题，6px 间距并垂直居中；标题按内容收缩，置顶占位稳定。项目／会话置顶仅悬停或键盘聚焦显示，已置顶也遵循该规则；触控稳定可达。收藏只在更多菜单，不显示常驻星标或重复置顶菜单。

会话与待办悬停及键盘聚焦背景统一使用主题 hover。任务行约 56px 最小高、8px 上下内边距、5px 圆角；当前精确尺寸和图标以原型 CSS 为准。

### 待办分组

待办输入固定，行首完成、中间标题编辑、行尾更多。待处理使用轻量 16px 圆圈，悬停／聚焦可用完成按钮时出现淡勾号，已完成用圆圈内勾；分组展开箭头和完成图形明确区分。

「待处理」「已完成」始终可见，显示数量；默认待处理展开，已完成入口在底部。点击任何分组只展开该组，点击已展开组则切另一组，空组仍保留入口和空态。网格高度与箭头约 200ms 过渡，减少动态效果时立即切换。

两组分别独立滚动、按项目记忆，收起面板 inert 且不参与焦点。完成／重新打开不自动切组，保留连续操作焦点；搜索或统计定位先展开目标组，再滚动、高亮和聚焦。状态变更撤销入口不因普通提示丢失。

## 4. 主题与文字

| 设置项 | 行为 |
| --- | --- |
| 跟随 DSH | 继承宿主配色变量及明暗外观 |
| DSH 默认 | 固定 DSH 配色，明暗跟随宿主 |
| 清爽 | 冷白、森林绿及工具式排版 |
| 温暖阅读 | 纸色、棕色；页面／章节阅读字体，控件与列表使用 UI 字体 |
| 紫晶工作台 | 白底、冷灰与紫色强调 |

主题选择共五项；其中四套独立配色各有明暗外观。工作台不设独立明暗模式，原型顶部宿主模拟控件不代表正式插件入口。

颜色分别使用正文、辅助、panel、hover、主按钮及其文字、选中底色／文字、危险、焦点、勾选边界、控件线及语义状态令牌。普通文字目标对比度至少 4.5:1，必要图形至少 3:1；源码计算不替代整页验收。当前实际令牌见 `src/client/theme.ts` 与原型。

紫晶关键令牌：

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面／表面 | `#ffffff`／`#ffffff` | `#1b1c1f`／`#242528` |
| 整体卡片／悬停 | `#f5f6f7`／`#f3f4f6` | `#242528`／`#2a2b30` |
| 正文／辅助 | `#1f2329`／`#636973` | `#e8eaed`／`#9099a3` |
| 边界 | `#e5e6eb` | `#333539` |
| 主按钮／文字 | `#8046f3`／`#ffffff` | `#a688ff`／`#14101f` |
| 选中底色／文字 | `#f1ebfe`／`#6d35e0` | `#2e2a3d`／`#b99cff` |

布局切换与置顶选中仅用底色和图标色，不叠加描边或内阴影，键盘焦点保留。输入聚焦用中性细边框与淡外圈，复合输入只在外容器提示，不叠加内层下划线。运行／异常／归档结合图形及文字或无障碍说明，不只依赖颜色。

桌面主要更多、完成和布局操作以 32px 为目标，触控 44px；桌面置顶为 24px，触控稳定显示并扩大目标。详情文字与控件使用 UI 字体，温暖主题仅页面和章节标题使用阅读字体。图标直接同步原型 SVG。

## 5. 抽屉、菜单与搜索

设置及统计使用底部抽屉：桌面 90vw，左右各 5vw，顶部 50px，底边贴窗口；只保留顶部 16px 圆角，约 300ms 上滑，减少动态效果时取消动画。标题和底栏固定，中间独立滚动；650px 以下全宽并使用顶部分类，考虑安全区域。

设置四分类为首页显示、主题、通用设置、项目权限。主题卡桌面两列、窄屏单列，五个选项自然换行。主题即时预览，保存保留、取消恢复，跨分类／项目草稿保留。统计抽屉为明细查看，底栏关闭。

默认项目根目录与已有项目目录使用统一目录输入组件。点击输入框或文件夹按钮打开宿主本地目录选择器，也可通过键盘手工输入，Alt + ↓ 打开选择器。取消选择保留原值，失败在字段下提示；选择中禁用提交。HTML 原型展示明确标注的模拟目录列表。

菜单继承主题底色、边界和状态，不窄于触发器，受实际视口限制，低高度内部滚动。项目选项显示名称与完整路径，重名可辨；打开聚焦首个可用项，方向键循环、Home／End 跳转、Esc／Tab 关闭并恢复触发器，禁用项跳过。

搜索悬停／聚焦／有关键词时加长，空白时不显示结果，输入框和浮层等宽、同左边缘，下方间隔 8px。结果按下方剩余高度限制并独立滚动；窗口缩放关闭临时菜单，保留草稿。

结果按项目／会话／待办分组，显示归属、真实摘录及归档／完成状态。宿主不提供命中数或消息定位时按当前限制说明，不用示例结果伪造真实能力。`⌘K / Ctrl+K` 聚焦、方向键选择、Enter 打开、Esc 保留词关闭。

弹窗及遮罩仅覆盖插件工作台显示区域，不覆盖或锁定宿主侧栏。设置抽屉按工作台高度计算，顶部预留 50px、底部贴齐；菜单和选择器定位限制在工作台边界内。打开弹窗只锁定工作台背景，Tab 在弹窗内循环，关闭恢复入口；下拉菜单的 Escape 先关闭下拉。列表重绘按实体或动作恢复焦点。长文本详情可选择复制，剪贴板失败仍能查看完整路径。

## 6. 异常、写入与验收

空、加载、错误在对应区域展示，失败保留成功数据；顶部同步失败提示数据可能过期并提供刷新。目录异常持续说明原因，待办和历史记录不丢失；归档内容业务只读，个人收藏／置顶不解除限制。

创建、编辑、归档、移除、删除、设置及布局只在保存成功后反馈成功或关闭；失败保留输入和原状态。当前宿主受阻的项目归档、迁移、永久删除不得因为原型存在而宣称实现。

实现按原型进行 1:1 核对，覆盖页面布局、SVG、控件尺寸、菜单、弹窗、悬停与焦点。现有 [插件视觉报告](ui/verification/index.html) 覆盖 DSH／清爽／温暖阅读及不同宽度，是对应版本的证据；不代表紫晶或真实桌面已经视觉验收。

当前验证范围、重跑方式和剩余差异见 [开发日志](../.agents/notes/dev-log.md)。HTML 原型保留，旧原型 PNG 与修订过程不再作为现行设计说明。
